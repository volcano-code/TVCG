## 1. 当前判断与并行关系

- 用户已确认旧配置的隔夜训练失败；最新看到的是 E5 汇总，最终完成轮次、最终更新数和终止原因仍须原始日志核实。
- 不把 E5 汇总自动解释为最终轮次；不把旧三轮的 819 次更新写成整次隔夜训练的最终更新数。
- Work A 的目标是冻结证据、解释准入、补齐定向诊断数据；数据扩容本身不构成模型改进证据。
- **Work A 不阻塞 Work B 对已有权重进行路径诊断、训练侧梯度审计与吞吐归因。**先交旧快照资产，补标并行推进。

- 暂不要求全面升级至 512/1024；高分辨率或连续材料对照仅在具体误差证据支持时另立受控实验。

## 3. A1：解释已登记但未准入的数据，优先复用

- [ ] 以已登记记录为全集，逐条连接 `record_id → source_snapshot → 原始资产 → 当前准入状态`，登记数与去重数分别报告。
- [ ] 对未进入本轮的记录填写实际原因：教师语义不一致、材料不合格、导数无资格、来源隔离、缓存缺失或其他可验证原因。
- [ ] 将“已合格但未加载”“仅 Moment 合格”“资格待核验”“确定排除”分开；不要用一个笼统的无效标记遮蔽可复用数据。
- [ ] 缺缓存或文件定位失败先修复资产可读性再复核；不能据此推断物理标签错误，也不能直接宣告合格。

- [ ] 每条状态变化附原状态、新状态、证据引用和复核原因；审计必须包含失败、待核验和排除项。

## 4. A2：首批约 24 条合格轨迹查询

- [ ] 从训练来源的原生成功轨迹中选择约 **24 条合格轨迹查询**作为首批目标；数量服从可验证成功轨迹与准入质量。
- [ ] 24 条查询不等于 24 条独立轨迹，也不提供充分统计保证；报告独立来源、几何、任务和轨迹的真实数量。
- [ ] 覆盖初值、一般迭代、接近收敛的末段、通过原生验收的终点与合法邻域；重点补齐当前末段/终点空白。
- [ ] 末段和终点同时覆盖中保留与高保留；保留近零及低保留比例对照，不删除表现差的高保留难例。
- [ ] 固定并记录保留比例分箱边界与计算依据；样本不足的格子显式报零，不看结果后重画分箱。
- [ ] 每条查询绑定 `trajectory_id`、原生任务、迭代序号、阶段、保留比例、终点验收凭据与参数邻域位置。
- [ ] 轨迹成功须由原网格上的原生验收确认；不能用代理模型残差、小梯度或确定性积分收敛替代物理成功。
- [ ] 邻域查询记录扰动方向、原始参数尺度与距离；原生终点成功不自动证明其每个邻域查询或导数均有资格。
- [ ] 同一轨迹内相关查询按轨迹分组报告，不能作为多个独立成功任务计算成功率或置信度。
- [ ] 先交可核验的部分批次及缺口表；不为凑足 24 条纳入来源不明、未验收或不合格标签。

## 6. A4：统一物理身份，不预设新标签更准

- [ ] 每条绑定原网格、材料资产、密度、单位、坐标系、固定材料、原生任务、教师版本、切割配置与保留侧。
- [ ] 教师必须对应部署所用的同一个**有限、有向、带端盖切割操作数**及其顶点运动；不能换成无限切面或其他教师语义。
- [ ] 固定材料只计一次；完整材料十矩校验必须绑定相同材料、密度、单位与坐标约定。
- [ ] 同一个面的换侧互补与独立 `+c/-c` 构面分开记录；不得恢复独立构面的错误互补约束。
- [ ] 标签中的 Moment 与 Jacobian 指向同一个物理目标；教师或材料改变时另立身份，不与旧标签冒充同目标配对。
- [ ] 完整材料十矩守恒、部分切割精度、最终原网格验收分别提供证据；其中任何一项都不能替代其余两项。
- [ ] GL2/GL3 属于确定性积分对照，不自动等于原网格硬布尔真值；不假定新数据、更多数据或更高分辨率标签更准确。
- [ ] 如各方法在同材料上共同偏离原网格，另交独立高分/连续材料对照及差异解释，禁止混入旧材料配对分母。

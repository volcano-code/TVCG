# Compact PINO V2.1 · 256³ 物理原型与训练准入

**2026-11-25 后续复核**已用新版有限切割接口重新计算下述 89 条开发查询。最新数值、切割稳定性的适用范围及三臂 Pilot 判定见[有限切割接口报告](stratum/README.md)。下文保留首轮物理原型使用历史部署接口时的测量。

**材料与原生轨迹复核通过。三臂 Pilot 和长训练的结论均为 NO-GO。** 部署版原生切割器在正式开发集的全部 64 条 R3 平面查询和 25 条 R8 抛物面查询上都拒绝构造对应的有限切割面。缺少同一物理配置的受限 Jacobian 监督。下表记录无训练物理原型对已有成功轨迹的误差。V2.1 已验收的陀螺成功率、求得合格解的耗时、可晋级 checkpoint 均无测量值。

## 冻结的数据与对照

本轮取自 Work A 正式四划分发布 `four_split_delivery_392`。发布清单 SHA-256 为 `ad11371d93f59db683a57682b107e65fdf7e83e650d427ee44265b93107a370d`。训练为 111 件几何、7,162 条查询，开发为 4 件、222 条查询。协议在提交 `9115f23` 预先登记，对照基线为 `54e8025`。192 条实际原生调用覆盖 14 件几何，包括历史诊断、符号、缩放、边界和互补对照。按正式查询 ID 和原始系数逐位相符计算，训练命中 13 条，开发命中 90 条。后两项是抽查覆盖数。外部盲测对象 `cad_elbow` 的身份已登记，其标签和求解结果留待合格候选晋级后使用。

8 件几何具有已登记的 256³ 表示。其余 6 件历史 Objaverse 几何只登记过 1024³，本轮从同一个原始网格调用 Work A 编码器生成 256³ 诊断对照，每件独立抽查 32,768 个中心。它们只用于描述跨几何误差。抽查中同时成功产生数值 Moment 的其他几何有 10 件。重复的符号、缩放和保留比例查询共享几何，不能据此估算独立泛化率。

## 实现与输入条件

1. `v21_native.py` 调用部署配置构造实际有限三角切割面。输入包含封盖、操作侧和顶点运动。源构造结束后，预测路径只读取这些条件。独立教师路径才运行 Cherchi 材料布尔运算并积分。
2. `v21_material.py` 在求解器目标坐标下，从已配准的闭合、有向原始网格构建 256³ 静态材料缓存。每个体素使用正权重，保留局部体积、质心和二阶矩；固定材料在最终累加一次。仅有二值 RLE 的场景适用表中的“有限面 + 二值 RLE”对照。只凭二值 RLE 无法恢复网格内的亚体素材料分布。
3. `v21_response.py` 在原生有限面附近的一体素半宽带内，根据有符号距离计算有界局部保留比例。在完全保留或完全去除的空间块上直接累加十矩。Jacobian 沿同一响应传播原生顶点速度，含封盖运动和原始系数归一化。事件资格、导数存在性和材料物理验收独立记录。
4. `CompactPINOv21` 提供 Token8/Token16 可学习入口，重用 P-CRAFT 的 32³ 与 64³ U-FNO，共享权重。部件注意力计算与查询无关的几何上下文，实际的查询交互通过有限面距离、顶点运动和带内局部响应进入。合成算例验证了仅对 Jacobian 反传时 U-FNO、token 嵌入、注意力和响应参数都有梯度，参数更新使旧特征失效，重建可恢复预测。下列结果均来自无需学习权重的确定性对照。

## 同一成功轨迹上的物理误差

面条种子 0 一共调用原生函数 25 次。24 次产生物理结果，保留后三角网格哈希全数一致，十矩与冻结记录最大绝对差为 0，原始 Jacobian 最大差为 1.78×10⁻¹⁵。第 3 次调用复现了原锥面参考不存在的拒绝。16 个接受的连续迭代有可核对的前进方向。

横向比较使用完全相同的查询。面条 24 条，其他 62 条。十矩分别用可编辑材料总质量乘以特征长度的对应幂次归一化，取最差分量再算查询 P95。单位方向 J 在单位系数尺度取最大分量行范数；Jv 使用原生实际接受方向，分母为原生 Jv 的二范数。正侧曲面对照使用同一平滑函数、带宽和二值节点。两个标量 token 对照还拿到了由细粒度计算给出的各 token 保留质量及其导数，单独检验丢失材料位置的影响。

- 面条局部位置方案的原始 Jacobian 相对 Frobenius 误差 P95 为 **0.1386%**。不同归一化方式回答不同问题，原始矩阵、各分量绝对误差和实际方向向量均在逐查询记录中。
- 面条的 557,463 个部分占据体素中，有 253,158 个中心落在材料外。所有 14 件几何及解析对照中，守恒材料的静态十矩最大归一化分量差为 **8.63×10⁻¹⁴**，预登记上限 10⁻⁸。长柱子算例的轴向质心误差从 Token16 单比例的 1.042×10⁻³ 降到局部位置方案的 3.165×10⁻⁶，薄壁、空腔和断连对照也有记录。
- 低保留比例仍有较大尾部误差。其他几何中该组 21 条的单位方向 J 误差 P95 为 **8.22%**，最差为 `T2_low_ELLIPSOID` 的 **41.80%**。近零比例只有 1 条可计分的其他几何查询。
- 对同一冻结切割面分别取交集和差集，两侧原生可编辑材料的十矩之和与全量的最大绝对差小于 4.22×10⁻¹⁷。用相反系数重新生成有限面会改变封闭边界，T2 和 combB 双曲面的质量和分别偏离可编辑总量 1.048×10⁻⁴ 和 8.499×10⁻⁶。实现仅对同一冻结边界使用互补律。

## 训练、Newton 和速度

全部 192 条调用得到 90 个可用切割面、89 份十矩、86 个数值完整 Jacobian。86 个完整 Jacobian 的独立事件证书数量为 0。完整、R3、R8 使用各自的可用性标志。生产配置对所有开发 R3/R8 的有限面生成及完整物理调用都返回拒绝。切换原生配置可以在独立诊断上得到与差分吻合的 10×3 和 10×8 导数，切割边界的定义也随之改变。该配置的结果只在原生报告的独立章节出现。

训练集的三件已登记几何支持静态平衡最大质量请求。8 段短原生轨迹得到 21 个接受的试步，缺少可评分的回退和收敛终点。S001 给出了直接反例，在原始起点十矩完全相同且单位方向 J 仅扰动 **2.0994%** 时，原生 Newton 的 13 阶增广方程秩降为 12，求解器在第一次调用后停止。未改动的求解器在同一点接受了第一步。因而 **1% 十矩、5% 方向 J 只能作误差筛选**。独立的求解验收仍需核对约束秩、步接受、最终原生约束及目标值。训练样例没有登记旋转接触姿态，静态反例不能估算陀螺成功率。

在同一对 CPU 核上回放面条种子 0 的全部 25 次调用，确定性原型热缓存下只算 Moment 用 **74.10 秒**，联合计算 Moment 和 Jacobian 用 **74.07 秒**，峰值进程内存 **1.38 GiB**。联合读出的冷缓存回调用时 76.58 秒，另有进程初始化 9.24 秒；计时从已生成的静态材料索引开始。逐次调用均包含有限面构造、封盖和物理边界检查，第 3 次拒绝也计入总时间。相同 CPU 核的原生历史日志记录联合回调总计 329.44 秒，求解加独立验收 354.16 秒。V2.1 本轮固定了查询顺序，未执行候选 Newton、线搜索和回退，核验合格解的总时间留空。[双核实测](profile_inference/summary.md)

**下一项应修改部署教师和求解器共同使用的有限切割面接口。** 对秩亏平面和抛物面，在同一物理配置、操作侧和封盖规则下提供可复核的固定秩运动及受限导数，复跑这 89 条查询的双步长差分和事件检查。通过后再补齐训练/开发物理覆盖与资格。此后按既定方案比较匹配输入的 CompactLite、Token16、Token8，沿用相对各臂 epoch 0 的 5% 晋级及 Jacobian、中高保留比例保护。真实求解审批另以成对种子、独立网格验收和取得合格解的全程时间为准。

```bash
sha256sum -c SHA256SUMS
python experiments/compact_pino_v21/native/verify.py
python experiments/compact_pino_v21/verify_results.py --include-solver-audit
```

V21_NOODLES_PACK=/tmp/compact-v21-fresh/indexes/noodles bash experiments/compact_pino_v21/profile_inference/reproduce.sh /tmp/compact-v21-timing

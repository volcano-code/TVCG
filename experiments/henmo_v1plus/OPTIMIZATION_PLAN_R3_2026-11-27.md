## 2. 合理性审查

### 2.1 保留正确契约

- 保留同一个有限、有向、带端盖操作数及其顶点运动；固定材料只加一次。
- 保留正权原子、完整材料十矩校验、最终同一个 Moment 的 Jacobian。
- 当前混合导数和物理归一化已经接入；本轮测量它们的作用，不把已有实现描述为缺失。
- 不重新引入独立构面 ±c 的互补硬约束，不改教师语义和原生验收阈值。
- 不将 GL2/GL3 平滑积分当作原网格硬布尔真值，不用模型自身驻点残差代替最终物理验收。

### 2.2 先定位再改目标

已知训练与评估路径不同，但尚未证明这是唯一根因。路径诊断和梯度审计均不更新参数，原始权重、梯度、RNG、模块模式和配置恢复。相同粗路径的零学习修正与 fine GL2/GL3 分别报告。

特别处理 `coarse_grid == leaf_grid`：例如 adaptive64/leaf64 会直接由细积分计算边界输出。其精度不能解释成学习分支的收益。因此诊断显式输出 adaptive32 与 adaptive64，不只给含糊的 adaptive 标签。

### 2.3 性能整改不改变目标函数

新增有界静态输入缓存，默认每模型256 MiB，可用 `HENMOOperator(config, static_input_cache_bytes=0)` 禁用。缓存材料聚合、编码输入和占据/距离/边界图；每次参数更新后的 learned table 仍重新计算。键绑定材料/层级、物理网格、固定材料、密度、编码网格、设备和dtype；入口保留原材料变异检查。

这消除已确认的重复准备，不预设 GPU 总体加速倍率。多几何层级对象仍不是完整全局缓存，树构建、CPU最近面查询、编码器和反向成本仍需剖析。

### 2.4 防止诊断再次污染训练

- 开发侧只做无更新路径诊断，分项梯度校准只接收训练记录。
- 细化与门控 trace 可有同步开销，不能拿其时间当正式吞吐。
- qualified J 缺预测时，诊断或校准不能算完整；缺标签与缺预测分别记录。
- 固定层级 screen 是新阶段：精确复制源权重，新建 Adam，更新/曝光从零开始，不载旧 optimizer 后冒充精确恢复。
- 对每个 source snapshot 继续执行原有准入；不改 role 绕过隔离。

## 4. 最小执行次序

### P0：免重训定位

1. 先用 E0 和第819步，在选择文件的12条开发查询/13条训练探针上对照；若成本高，先 `--limit 6`，记录该缩减。
2. 第273/546步优先只复放已观察到跳变的查询，不要求四个checkpoint乘以全222条。
3. 对相同训练探针分别测coarse32/coarse64的分项梯度。先检查导数资格与梯度是否完整，再判断失衡。
4. 记录粗/细输出、门控导数项、frontier材料质量分布和实际fine调用。frontier是非重叠初始边界分区；多层节点计数不能当作总体积比例相加。

| 观察 | 下一步 |
|---|---|
| coarse改善但原部署adaptive32退化 | 修正最终响应监督或层级一致性；先明确共同物理目标，不直接全量改adaptive训练 |
| 固定训练探针也无法拟合 | 查局部响应/材料/教师，并做有数值证据的有界保留率拟合；拟合失败未收敛不能当表示下限 |
| M-only改善，joint退化且分项梯度支持冲突/量级失衡 | 训练侧校准λ或更新日程，单因素对照 |
| 训练改善，开发退化 | 优先补独立来源、曲面与轨迹阶段；保持旧开发配对 |
| 输出主要由fine承担且更慢 | 先量清神经贡献；确定性路线与旧精度最好V2仍作为工程候选 |

### P1：有界训练对照

在P0支持的层级上，固定同一个源checkpoint、同一训练池、seed830251、Adam3e-5、batch1、FP32网络/FP64矩、辅助损失0。先比较M-only和joint(λJ=1)，各128次真实更新；查看方向后最多延至256。校准臂需要同源checkpoint、同快照、同层级、导数完整且无参数更新的训练梯度报告，再显式登记λ。

`screen` 的训练与主要诊断评估都采用声明的同一coarse路径。其结果只用于学习性/目标归因，**不能冒充旧adaptive协议晋级**。结束后用该阶段导出的 `model_config.json` 和权重，再运行八路径诊断及原部署路径完整评估。

不要从第819步盲目续训；它可作为归因权重。新阶段源权重需按诊断选择并登记。不得只把较差起点作为容易超过的E0，不报告确定性与旧模型对照。

## 5. 扩大预算与最终验收

原5% Moment改善与+5%保护线继续用于原声明路径，不能看结果后放宽。固定coarse诊断不是原协议的复验。另列与同粗零修正、fine GL2/GL3的精度/成本关系。

扩大预算要有：联合目标稳定改善的证据、已定位且受控的尾部异常、真实末段/终点诊断与明确净收益路径。完整独立来源/50种子/全成本评测用于最终部署与论文，不阻塞短诊断，也不能省略后宣称论文加速。

本轮尚未证明原配置退化已消除，没有发布合格训练权重。具体执行及交付见本目录R3的Work A、Work B清单。

## 3. B1：补齐真实模型接线

### 3.1 编码与配置

- [ ] 现有 V2.4 配置契约只允许 64/128；集成时另设显式 32/64 对照配置与身份，不能临时手改配置绕过校验。
- [ ] V2.4 构造/恢复/推理均显式读取编码网格；64³、128³ 各执行真实 forward，并在材料 token/积分点位置读取特征。
- [ ] 128³ 不是 64³ 上采样。材料仍为 native 256³；记录 feature map shape 和各阶段显存。
- [ ] 保留共享 P-CRAFT/U-FNO；本轮不同时改变宽度、频率数、层数、积分规则、带宽。
- [ ] 配置序列化并纳入 checkpoint/cache 身份；不得仅凭 state_dict 张量形状相同猜测编码分辨率。
- [ ] E16 权重只迁移可兼容部分，报告 mapped/new/missing/unexpected 项。新 run 重建 Adam，不把新增参数和网格变化伪装为旧 checkpoint 精确续训。
- [ ] 静态材料缓存按网格、密度、坐标、固定料和算法版本；学习特征缓存另按权重版本/网格/设备/dtype。
- [ ] 解冻任何影响静态特征的参数后不得跨更新复用旧学习特征或已消费的计算图。

### 3.2 切割条件与有界响应

- [ ] 从同一原生有限、有向、带端盖操作数构造切割描述；不用真实布尔结果或切后真值作为输入。
- [ ] 首版 16 个 cut tokens、192 维、4 头、1 层；活动材料 token 先压缩再注意力。
- [ ] 记录 N_active、N_cut、每头注意力元素数和实际耗时；不能仅给掩码却仍计算所有材料 token。
- [ ] 首版把顶点运动作为导数传播信息，不把随 c 变化的 V_c(c) 当成无额外导数的学习输入。
- [ ] 两通道动态修正加入原响应的有界参数化之前，再执行既定 tanh/约束；不能把无界 delta 直接当保留率。
- [ ] 使用同一内部保留场产生交集/差集，保留侧只路由，不分别学习两个不受约束的场。
- [ ] 所有十矩来自同一组正权重积分点。固定料只加一次。

令 z(c) 表示切割条件经注意力得到的动态响应参数、s(c) 表示局部距离，则必须包含：

dr/dc = (∂r/∂s)(ds/dc) + (∂r/∂z)(dz/dc)。

旧解析斜率捷径只处理第一项，不能直接复用来冒充完整 J。法向、端盖、坐标变换、系数归一化、局部插值等实际依赖都属于链的一部分。若积分节点/权重随 c 变化，还须加上它们的导数；首版保留静态节点/权重以控制复杂度。

有界保留率继续成立，但加入动态参数后不能未经证明宣称对所有切割系数单调。活动集/最近特征切换附近应重新做扰动资格或回退；不能把跨事件的差分当光滑导数。

### 3.3 高阶反传与优化器

- [ ] 默认 higher_order_safe=True；CUDA 上复跑 J-loss backward，不能只检查一次普通 backward。
- [ ] 建立 explicit 参数组：cut descriptor encoder、cut attention、响应头；后续可选几何融合/编码器组。
- [ ] 不直接套旧 training_scope=response，否则新 attention 可能不在 optimizer 中。
- [ ] 连续至少 5 次真实 M＋合格 J 更新，记录每组梯度、参数变化、分母、拒绝和非有限数。
- [ ] 零初始化可能使新注意力在第一步梯度为零，之后才打开；检查连续更新，不能强制第一步每个参数非零。
- [ ] 从中途恢复下一次更新，核对权重、Adam、随机状态、采样顺序与累计曝光。
- [ ] 全保留/全剔除无活动点时，正确处理常量输出和空梯度；不得因此生成伪学习样本。

## 4. B2：把三类门槛分开

### G0：允许研究训练的实现正确性

1. 真实编码 shape、数据/教师语义、正权重、有界响应、固定料和同面互补通过。
2. 同一编码网格下关闭新分支，能够复现旧输出；32/64 改 64/128 后不要求 E16 逐值相同。
3. 完整模型 J/Jv 与独立 AD、多步长有限差分在有效邻域一致，R3/R8 在各自固定秩空间扰动。
4. 实际 CUDA M＋J 更新及恢复通过，新的训练参数均按设计学习。
5. 显存与活动节点上限可承受。

数值一致性阈值应在真值可解析的训练侧案例、双精度参考与实际 float32 路径上事先冻结；按 mL^k 和系数尺度分别报告绝对/相对误差。它不是要求未训练网络先匹配最终原生物理精度。

Full J 无合格数据时可继续 M/合格 R3/R8 研究训练；需在报告中明确适用范围，不能声称通过 Full J 物理泛化。

### G1：增加训练预算的筛选

- 沿用历史配对：来源宏平均原始十矩 RMSE 相对本臂 Epoch 0 改善至少 5%；受保护 R3/R8/Full J、中/高保留不超过初始的 1.05 倍，有效分母单列。
- 同时与冻结 E16、同输入无学习积分器比较；“比自己更差的初始化改善 5%”不等于比 E16 好。
- 固定 222 与新增开发集分别报告；逐来源、逐分量、P95/P99、最差查询、末段/终点误差不可被单一宏平均替代。
- 该 5% 是研发筛选，不是物理容差或显著性证明；阈值需要修改时只在查看新候选预测前预注册。
- 如果 J 与 FD 不一致，优先修代码；如果一致但对教师 J 误差增大，应查数据覆盖/损失/近似，不能直接认定漏导数。

缺少已注册保护项的有效分母时，该项保持“证据不足”，不得签发原完整协议的正式长训 GO。实现正确后可按事先声明的适用范围与上限继续研究训练（包括获准的最多 60 轮研究预算），这不代表对应物理能力已验收。

### G2：允许作为求解加速器

- 独立原网格验收使用原驻点与平衡标准；对应冻结协议为 1e-12 与 1e-6，不得降低。
- 同初值下原生可解任务无新增未恢复失败；所有回退计入时间，不能把纯原生回退的成功归功于网络精度。
- 目标相对原生误差按既定协议不超过 1%，并分别报告方向接受、Newton 步数、校正次数、直接/混合通过率。
- 总耗时从读原网格开始，包含构面、传输、失败、回退、校正与最终验收。论文推广使用封存独立来源和预注册 0–49 配对初值。
- 候选/原生配对耗时比的 95% 区间上界 <1；多来源统计按来源/几何聚类，不能把一件几何的 50 个初值当 50 个独立几何。

## 5. B3：短试先筛选，避免六组长训

对照矩阵：32/64 与 64/128 × 无动态条件、同描述 MLP、活动区 cross-attention，共六个格子；共享材料、教师、数据、损失、曝光次序及初始化协议。无动态条件仍保留原有切割距离响应。

- 第一轮每格最多 3 epoch，先冻结相同曝光次序与尝试预算；真实提交、空梯度/拒绝/跳过次数另报。若实际提交数不同，不能声称更新预算也完全相同；需要时另做匹配提交数对照。已完成且可精确复用的结果不重复跑。
- 最多两条较优路线继续到总计 10 epoch。
- 一条胜出路线继续到总计最多 60 epoch，使用平台早停；总计包含前述短试，不是另加 60。
- E16 既作为固定部署基线，也可做相同新增训练预算的响应更新对照；二者分开标注。
- 先关闭新增残差损失以隔离架构收益；后续只对选中的架构独立评估残差匹配，不同时换模型、积分带宽和损失。
- 如果 attention 不优于同输入 MLP，选择更快的模型；正式论文再补足必要消融和多个训练种子。
- sparse 256³ 特征仅在可复现的局部表示误差出现后另开对照；512³ 不作为首版默认。升级原生材料分辨率是另外一个实验。

## 6. B4：训练与性能配置

采用同目录 TRAINING_RECOMMENDATION.yaml 中的建议。它是集成契约，当前旧 Trainer 不能直接读取全部字段，必须实现参数分组、网格还原和新训练范围后再使用。

默认：RTX 5090 D、Token16、batch=1、Adam 3e-5、seed=830251、AMP off、积分/物理归约 FP64。新动态模块和响应一起训练，预训练静态主干先冻结。若有明确表征瓶颈，另起可比较的解冻实验，几何层 LR=3e-6，重建特征缓存。

B1/B2/B4 批量比较应保持同一数据曝光和学习率；如需相同优化更新再另做匹配对照，不能同时声称两种不同预算相同。梯度累积比较时，M 与各类 J 使用各自全累积窗口的有效分母，不能简单平均含缺失标签的微批 loss。

按阶段记录：材料/索引、静态编码、每次原生构面、距离/活动点准备、切割 token、注意力、局部响应、M-only、M+J、传输/同步、原生校正、最终验收。训练样本吞吐与单次求解耗时分开。

# Compact PINO V2.4 — Work A 数据与教师行动指南

日期：2026-11-27（北京时间）。状态：可立即进行的数据工作；配合 V2.4 集成，不代表已有 V2.4 合格权重。

## 1. 任务与当前事实

目标是让模型学到“真实优化轨迹末段的准确十矩及合法导数”，并为动态切割条件提供可复现输入。保持 E16 / R1 与固定 222 条开发集作为历史基线。当前候选代码只完成注意力组件、活动 token 压缩和配置契约；完整 64³＋128³ 与 M/J 接线仍待 Work B 完成。

已有合格标签可以继续使用。把编码特征分辨率从 32/64 改成 64/128，本身不改变物理教师，也不要求全部重新标注。只有教师、坐标、密度、固定材料、切割语义或资格发生变化时，才对受影响的标签重新生成并发布新身份。

## 3. A1：先交 24 条小规模集成样本

建议沿用已提出的小包：至少 3 个训练来源、4 件几何，每件 6 个合法查询，共 24 条。每件尽量包含初值、一般迭代、2 个末段点、1 个独立验收通过的终点、1 个合法终点邻域。不得把任意中保留点标作优化终点。

- [ ] 终点必须有该任务的原生成功轨迹、冻结验收公式、约束、乘子和独立原网格验收。
- [ ] 必须包含非零固定材料；不能只用固定壳为零的简化数据。
- [ ] 保留各点的真实非零驻点/约束向量，普通查询不能强制标为零残差。
- [ ] 每条的 M、R3、R8、Full J、Jv 分别给出资格与原因；M 合格但 J 不合格仍是合法 M-only 数据。
- [ ] 提供真实 Newton 方向的单位化方式、方向向量和 Jv，不用任意随机方向完全替代求解方向。
- [ ] 另给同面换侧、端盖、最近特征并列、拓扑事件、非法参数图等拒绝/回退样本；事件不光滑时不得伪造连续导数。

24 条只用于集成与早期诊断，不能据此声称具备跨几何泛化。若某件几何原生无可行成功任务，记录失败并补充另外的合法训练任务，不修改验收阈值。

## 4. A2：动态切割输入契约

输入只能来自原网格的静态预处理，以及本查询允许构造的有限切割面。切后真实布尔材料、真实切后十矩、真值保留率、教师残差与真值拓扑，只属于标签/校正/验收，绝不能进入模型输入；单独计时也不能消除这种泄漏。

| 字段 | 用途与限制 |
|---|---|
| 顶点位置、面片、端盖身份、方向 | 与部署教师构面一致 |
| 局部位置、法向、曲率/局部曲面系数 | 来自可微的原操作数几何；不可来自布尔结果 |
| 坐标变换与参数图身份 | 标明原始十系数及 R3/R8 映射；不可混用归一化 |
| 顶点对系数的一阶运动 | 供 Jacobian 链传播；首版不作为任意学习特征输入 Moment 网络 |
| 活动区域与局部 signed distance | 由材料和切割面计算；资格事件单独记录 |
| 保留侧 | 用于同一内部保留场的交集/差集输出路由，不让两个独立响应破坏互补 |
| 资格及拒绝标记 | 由输入端可检测事件产生；教师事后拒绝信息不能泄漏为推理特征 |

若把随系数变化的顶点速度 V_c(c) 也喂给 Moment 网络，dM/dc 一般还需要 V_cc，单有一阶运动不足。首版避免这个额外依赖；未来确需采用时必须提供完整导数链。

Work A 负责几何和运动的可追溯原始记录；Work B 负责可微 token 化及其导数实现。不得把离线导出的 token 数值作为常量输入，然后声称该条件路径已正确求导。

## 5. A3：定向补充，分批交付

按以下次序扩充，后续批次不阻塞已合格快照上的第一轮研究训练：

1. 不同训练来源的中/高保留末段、真实终点及合法邻域，优先验证 m、z、zz 的相关误差是否普遍。
2. 不同来源的曲面查询和合格 R8；同时给每个来源及每条查询结果，不能让两条开发 R8 代表总体。
3. 可证明邻域有效的 Full J，以及真实 Newton 方向 Jv；没有资格时写“不可评价”。
4. 薄壁、空腔、断连、端盖和活动区域变化。
5. 近零/低保留、高保留和一般迭代对照，防止只改善终点平均值。

首批扩展建议以 8 个训练来源各至少 1 条原生成功轨迹为目标，每轨迹采 6–12 个有代表性点；这是任务组织起点，不是样本量充分性证明。覆盖不足的来源可分批交付，不用复制少数几何凑查询总数。

补充开发集与训练来源独立，覆盖曲面、轨迹末段、保留档位及导数资格。其清单在揭晓新候选预测前冻结。面条已用于设计与诊断，不再充当盲测。封存几何必须绑定实际合法原生优化任务；一个文件名或几何本身不构成可用盲测。

## 6. 数据与物理检查

- [ ] 用独立网格积分验证完整可编辑材料全部十矩；按 mL^k 尺度，双精度各分量误差不超过既定 1e-8。
- [ ] 正积分权重非负；全部材料时重现零至二阶矩；固定矩只添加一次。
- [ ] 同面互补对可编辑部分验证：M_inter_edit + M_diff_edit = M_edit_full。
- [ ] 若两条总输出都含固定材料，它们相加会有两份固定矩；验收时不能误把这一项当成互补失败。
- [ ] 对新补的导数保存独立 AD、多步长有限差分、部署教师比较及参数图资格；事件不稳定的点只保留适用标签。
- [ ] 已有标签语义未变时复用其资格，不为网格特征升级无谓重做全部教师。
- [ ] 训练运行读取冻结快照，不在进程中悄悄追加后台样本。

# Compact PINO V2.4 更新、架构与研发判断

日期：2026-11-27（北京时间）。
复核起点：研究分支提交 558a24df380b7e7120a6072c678885b218e1eb7b；本文件随本次后端修复与新行动指南共同提交。以承载本文件的 commit 为交付版本。

## 1. 一句话结论

保留 256³ 守恒材料、统一十矩/导数与原生校正，新增真实 64³＋128³ 编码候选和活动区切割条件注意力。已有组件代码与本次高阶反传修复；完整 V2.4 算子尚待接线、CUDA 联训和物理验收，不能称为已训练完成。

本次发现：PyTorch 2.8.0+cpu 下，旧组件默认注意力一阶 J 可与有限差分吻合，但 J-loss backward 报 CPU flash backward 未实现。默认切换到 SDPA MATH 后，十矩→10×10 J→J loss 的回归通过。该结论不代表所有 CUDA 后端必然失败，也不证明完整物理算子已经正确。

## 3. 更新后的目标架构

1. 原网格一次预处理：256³ 原生守恒材料、完整体素解析矩、边界正材料积分点与固定矩。
2. 静态编码：共享 P-CRAFT/U-FNO 对 64³ 和 128³ 真实执行；局部特征汇入 Token16 和静态缓存。
3. 每查询：由原系数构造同一部署有限、有向、带端盖切割面，保留合法运动信息。
4. 动态交互：16 个初始 cut tokens；仅活动材料 token 通过 1 层、4 头、192 维 cross-attention 读取切割上下文。
5. 响应：动态调制两个局部参数，经有界映射得到 r_l∈[0,1]。不直接自由回归十个矩。
6. 积分：M_hat = M_fixed + Σ_l w_l r_l phi(x_l)，w_l≥0；phi 的顺序为 (1,x,y,z,xx,yy,zz,yz,xz,xy)。
7. 导数：J_hat=dM_hat/dc，包含距离路径和切割条件/attention 路径；R3/R8 在各自合法参数图下计算。
8. 求解：神经提案、必要原生校正、独立原网格验收；最终仍使用冻结物理标准。

64/128 是特征分辨率，256 是材料分辨率，Token16 是空间 token 划分；三者不相等。可选稀疏 256³ 局部特征属于后续实验，不默认启用，不能凭特征插值恢复原材料已经丢失的薄壁信息。

“全部材料十矩守恒”不保证“每种部分切割都精确”。局部积分、平滑带宽、薄壁与端盖仍可能产生误差，需保留无学习积分器作对照。

## 4. 当前已训练版本的真实证据

V2.2/R1 冻结编码器、只更新 12,674 个响应参数，追加 55 轮、120,670 次更新。最佳历史 E16 相对 E3：

- Moment 来源宏平均原始误差改善 38.547%；
- R3 改善 24.240%，R8 改善 25.599%；
- 中保留改善 38.310%，高保留改善 44.092%。

固定开发集只有 3 个来源、4 件几何；R8 只有 2 条合格记录，Full J 和低保留无合格开发分母。combB/maskB 来源 R8 曾退化 78.626%，不能用宏平均掩盖。

Noodles seed 0：E16 直接输出的原生驻点残差约 0.00271657，未通过；原生校正后残差约 1.28466e-13，合格。该单例支持混合路线的可行性，不支持独立泛化或直接替代声明。

| 纯原生冷启动到合格 | 266.858744 |

静态编码只占这条记录约 0.715 秒，不能认定原 32/64 主干就是百秒总耗时的主要原因。128³ 可能通过更好提案减少后续开销，但不是自身计算更快。

## 5. 行动顺序

Work A：冻结旧身份 → 24 条合法轨迹小包 → 导出允许的切割面输入 → 定向补终点、跨来源 R8、有效 Full J/Jv → 封存独立原生任务。

Work B：实际 64/128 与 M/J 接线 → CUDA 高阶反传和恢复 → 小预算六格消融 → 最多两格到 10 轮 → 一格到最多 60 轮 → 独立物理和耗时测试。

任务详见 WORK_A_ACTION_GUIDE.md、WORK_B_ACTION_GUIDE.md；训练参数见 TRAINING_RECOMMENDATION.yaml。该 YAML 是建议契约，不是现有训练 CLI 可以直接读入的配置。

## 6. 训练配置与预算判断

默认 5090 D，batch=1，Token16，新动态模块＋响应 Adam 3e-5，初期冻结预训练几何主干，AMP off，物理归约 FP64。首轮 M+合格 J，J 权重 1，新辅助/残差项 0，以隔离架构收益；后续再校准固定参考残差匹配。若几何表示确需适配，可另开 LR=3e-6 的分层解冻实验。

3 轮短试 → 总计 10 轮筛选 → 最多总计 60 轮并早停；不以“必须训练满”作为目标。当前 E16 55 轮作业约 28 分钟，但新动态分支和可能解冻的 128³ 编码不具备同样成本，必须用前 200 次真实更新和完整验证估算。

批量从 1 到 2/4 以更新吞吐、显存和验证误差决定。大 batch 不能直接减少原生校正与最终网格验收时间，也不自动更准确。

## 7. 目标实现的判断

- 可训练的新模型：完成集成和 CUDA 联训检查后具备明确路径；目前不能宣称已有完成训练的 V2.4。
- 比本地原生更快获得合格解：已有一个混合成功例作为基础，有继续投资的理由，需多来源复验。
- 完全神经直出达到原生 1e-12 驻点阈值：现证据不足，不能保证；保留原生校正。
- 论文级结果：需在相同输入的 MLP、无学习积分器、E16、优化后的原生实现间证明净收益，补独立几何、配对初值、失败成本及统计区间。
- 相对原论文更快：当前代码、几何、硬件与计时口径不同，没有公平实测结论；不可把跨机器表格数值直接相除当作贡献。

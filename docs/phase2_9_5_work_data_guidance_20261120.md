## 1. 执行结论

**现有小数据集可以保留，作为有条件准入的探索训练数据；无需推倒重建。** 当前明确的使用范围是：19 个完整配额训练几何、1,251 条查询，在真实接口和单批反向传播验收后，进行 fixed／PCGrad 各 100 步的固定预算拟合诊断。

**目前尚不能把它作为正式完整长训、模型选型或泛化结论的数据集。** 独立开发集的合格监督仍为零；现有审核也没有证明这批数据已通过 M69 拓扑优化可行性验收。

当前阻塞主要来自三个方面：训练器此前没有完整接收受限导数的接口、数据存储坐标与模型坐标尚需通过实际 loader 对齐、教师标签对应的积分域与模型 RLE 域尚需明确。前一项由 Chat 修复模型代码；后两项由 Work 提供源机证据，双方共同完成接口验收。不能据此要求 Work 把全部几何重做、重标所有标签，或将有效受限导数伪造成完整 Jacobian。

用户已授权继续研发。本文件的准入条件是技术验收条件；满足后按冻结协议推进，不增加一轮仅为重复确认而设置的聊天审批。

### P0.2 明确“交叉项乘二”究竟存在哪里

Work 需要同时提供实际系数样例、教师多项式计算代码位置和 loader 是否转换的说明，明确以下哪种形式是文件里的原始数据：

1. 原生矩阵系数 `c`：多项式基为 `(1,x,y,z,x²,y²,z²,2yz,2xz,2xy)`。
2. 已加倍的单项式系数 `u = Bc`：基为 `(1,x,y,z,x²,y²,z²,yz,xz,xy)`，其中 `B = diag(1,1,1,1,1,1,1,2,2,2)`。

“交叉项乘二”这句话本身不足以区分两者。应给出至少一个非零交叉项查询的系数向量和若干固定空间点，核对文件、教师与模型三侧计算的多项式值和保留侧一致。

转换必须同时作用于导数和方向基。若 `c = A u`，`A` 是常量可逆换基矩阵，且输出保持相同的原始十矩定义，则 `J_c = J_u A⁻¹`，受限基为 `R_c = A R_u`。例如文件存 `u=Bc` 时，模型原生输入为 `c=B⁻¹u`，完整导数换为 `J_c=J_uB`，方向基换为 `R_c=B⁻¹R_u`。不得只转换 query 而保留旧 Jacobian／basis 坐标。若 loader 另有查询归一化等非线性操作，补其完整链式法则，不套用可逆常量换基公式。

**通过条件：** 用实际数值与代码位置确定唯一约定，说明输入、完整导数、受限基和受限标签的转换；转换后的有限差分检查在教师允许的可微范围内通过。若无需转换，也明确记录恒等映射及依据。

### P0.3 核对材料域、坐标与固定偏置

逐项确认以下内容，并在交接报告中引用实际文件或教师实现：

| 项目 | 审核单已有约定／本轮需补证据 |
|---|---|
| 空间归一化 | 外包围盒中心平移、最长边缩至 1；补原始到归一化的实际变换 |
| 密度与保留侧 | 单位密度，保留 `q>0`；补教师实现依据 |
| 矩顺序 | `mass,x,y,z,xx,yy,zz,yz,xz,xy`，后三项是原始交叉矩 |
| 标签范围 | 可变域离散十矩、固定偏置为零；核实是否所有首跑样本一致 |
| RLE 坐标 | 原点、格距、轴顺序、区间端点规则、原生 side 和实际区间数 |
| 积分几何体 | 教师是否积分同一 RLE 体素并集，还是网格／连续域或另一离散化 |
| 固定／可变分区 | 模型总矩与标签可变域矩的关系；不能重复加固定域或把它遗漏 |

对每个首跑几何至少给出“不切割的总十矩”的来源与对照；必要时再给能代表差异的切割查询。若教师域和 RLE 域不同，单独报告表示差异，包括质量和各阶矩差异，不将其全部归入模型误差。

保持连续参考诊断与离散教师监督分开。SQNO 平滑近似误差、几何离散误差和学习误差也应分别记录。容差沿用已冻结的教师／数据协议并写明数值和单位；如果尚无阈值，先定义适用于物理尺度的判据，再验收，不能看到结果后放宽阈值。

**处理原则：** 只有实际证据表明某个几何或查询的标签与目标域不一致时，才对受影响项修正或重新生成标签，并建立新版本指纹。保留原冻结版本以便追溯。

### P0.4 保留完整、受限、仅十矩三种监督

Work 提供原始字段至模型 API 的映射表。下面列的是模型接收语义，不是在断言现有 loader 已经使用这些字段名：

| 模型字段／语义 | 要求 |
|---|---|
| `target_moments` 与 `valid_mask` | 原始十矩、独立有效行；参与监督的值必须有限 |
| `target_jacobian` 与 `jacobian_valid_mask` | 对模型原生系数的完整 `10×10` 导数；缺失标签不填零 |
| `restricted_basis` | 原生系数方向，形状 `[Q,10,D]`；保留方向长度和排列 |
| `restricted_jacobian` | 与该方向基完全对应的十矩方向导数 |
| `restricted_valid`、`restricted_dimension` | 有效行及有效列前缀；首跑含 3 和 8 维，不能把填充列算进 loss |
| `event_valid`、事件标签有效性 | 独立语义；不能从完整导数是否可用推导事件类别 |
| normalizers | 从训练分区预先确定；记录 Moment、完整 Jacobian、受限输出尺度及指纹 |

完整导数和受限导数监督按既定互斥分类进入当前统一 loss。若源数据同时提供两种证据，须明确实际采用哪一种，避免同一查询被重复加权。受限监督比较 `J_pred @ restricted_basis` 与受限目标；先选有效行和列，再进行运算。不能先对含 NaN 的全张量做减法、投影或平方，再乘零 mask。

不要对 basis 单独做 QR、归一化或旋转。如果有充分理由改变方向坐标，必须同时变换受限标签并建立新契约。仅十矩样本仍可训练 Moment；无完整导数不等于样本无用。

有限差分只在教师声明的有效范围内验证：完整导数检查有效完整方向；受限导数只沿其有效基方向检查，并确认扰动曲线仍在对应参数流形内。非光滑事件、经典导数无定义或仅方向证据的查询，保留明确状态，不为了通过检查伪造完整导数。报告步长、单位、误差判据和失败原因。

### P0.5 明确本轮几何输入，避免把 SDF 文件存在等同于已接入

当前统一模型默认使用 RLE 派生的四通道上下文：体积分数、占据、由该占据计算的距离特征、边界，并保留原生 RLE 区间。它不会自动读取数据包独立 SDF。

**首跑可以明确使用这一 RLE 路径，无需为了等待外部 SDF 接线而重做数据。** Work 需要保证 RLE 与标签域一致，并在回执中注明 `external_sdf_used=false`。如果实际首跑配置决定使用外部 SDF，则另行提供坐标对齐、符号、距离单位、网格位置、分辨率、重采样规则、窄带／截断方式和数据指纹，并通过模型输入测试。

无论选择哪条路径，报告均要分别记录原生几何 side、P-CRAFT 上下文尺度和区间数。`side=512` 字段不能代替真实的 512³ 几何覆盖或 GPU 性能证据。

### P0.6 提供最小真实样例，并完成训练步验收

交接先使用 P0.1 的小文件。读取实际 loader 后，再导出一份显式文件清单，只选择已冻结训练分区中的样例，覆盖：

- 一个完整导数样例；
- 一个三维受限导数样例；
- 一个八维受限导数样例；
- 一个仅十矩样例。

若多类样例属于同一几何，可以复用其原始几何文件。包中保留源 `geometry_id`、`query_id`、切割类型、来源／家族、完整路径映射、源文件 SHA-256、实际导出的字段和值。附运行 loader 所必需的最少依赖源码和相应 RLE／必要几何文件；是否需要 SDF 由 P0.5 的输入选择决定。

不要裁剪原几何、生成随机占位张量或更换样例的积分域来缩小文件。样例文件较大时，先交付清单、大小与指纹，再按需要传递精确文件，不要求盲目打包整个数据集。小文件采集器的大小上限不代表几何样例的准入上限。

**P0 总出口：** 发布版本的软件回归、实际数据契约、代表样例和目标设备真实训练步均有可复核结果。单独的 handoff 成功、前向成功或参数哈希未变的 smoke，均不能代替这一出口。

## 6. P0 完成后的首轮 pilot 规则

以下配置沿用接续方案，实际执行前写入带指纹的 run manifest。架构、精度和 normalizers 在真实输入／显存预检后冻结；不根据最终训练曲线再修改规则。

| 项目 | 规则 |
|---|---|
| 对象与数据 | 固定 19 个首跑 ID、1,251 条查询；不混入剩余 88 个对象 |
| 比较组 | fixed／PCGrad 两个独立副本，同初始化、同采样序列、同更新步数 |
| 预算 | 每组 100 次优化器更新；相同步数不表示相同时间／FLOPs |
| 随机状态 | 接续方案为初始化 830501、采样 830502、逐步 RNG 起点 830503；实际值写入 manifest |
| 采样 | 均衡几何，再在几何内按五类切割抽样；核实每类可供应量后固定序列 |
| 监督 | 开启有效完整／受限导数，保留仅十矩；分别报告覆盖和误差 |
| 优化器候选 | AdamW，学习率 `1e-5`，weight decay `1e-4`，梯度裁剪 1；预检后固定 |
| 损失候选 | Moment 1、导数 0.1、分支辅助 0.25；记录受限尺度与逐查询平均语义 |
| 结果 checkpoint | 使用最后一步；中途恢复快照不用于挑选结果 |
| 输出 | 初末训练指标、各监督类型／几何／切割类型误差、梯度诊断、参数变化、时间与显存 |
| 允许结论 | 训练链路是否正常、能否拟合、是否存在数值与任务冲突问题 |
| 不由本轮确定 | 最终 Head、泛化、早停策略、PCGrad 优越性、512³ 加速或 M69 最终可行性 |

若数据不支持每步每类两个查询的既有建议，先记录原因并修改采样协议，再开始成对实验；不能在训练途中无记录地切换抽样。不得按预测误差选择“容易样本”纳入准入统计。

## 7. P1：正式训练前的数据整改

### 优先完成独立开发集

针对现有 16 个候选原网格逐件给出准入结果、阻塞原因和下一步。优先解决可以形成有效独立监督的对象，让开发验证从零推进；不能将已经预留训练的对象、模板或修复后变体改名挪入开发集。

训练、开发、锁定测试按几何、来源家族、模板／提示来源和修复血缘隔离，核查精确重复和近重复。仅有 query_id 无交集不足以证明几何独立。禁止把同一几何的查询随机拆分成训练／验证以填补开发集缺口。

正式目标仍为 200 个合格训练几何和 40 个独立开发几何，锁定测试另行冻结。分别报告候选、已处理、标签有效、最终准入数量。不能简单把“107 已登记”算成“107 已正式准入”，也不能把“16 个候选”算成“16 个开发对象已可用”。

### 处理剩余训练快照与查询覆盖

对剩余 88 个对象给出五类切割覆盖、有效导数覆盖、质量／来源缺项和可准入原因。补齐后形成新的索引与版本，不覆盖当前 19 对象 pilot 的冻结索引。正式标签覆盖应包含与优化相关的区域和事件状态，不能只通过重复容易查询增加行数。

### 统一正式实验协议

现有 `phase2_8_3_head_ablation_protocol.md` 默认每合格记录至少 256 条查询，训练／验证／测试至少 50／7／10 个独立来源组，并绑定 `m69.corpus.v1` 清单与审核。当前 pilot 每件 64 或 69 条查询，使用 Faster107 接口，不自动满足该正式协议。

200／40 是几何规模目标，50／7／10 是该既有协议的来源组要求，二者不能互相替代。正式候选训练前，由双方明确最终采用的 manifest、来源分组和查询预算；确需调整时形成预先登记的协议修订，不能为让现有数据“变绿”在运行后降低阈值。

## 9. 故障定位与整改决策表

| 现象 | 责任与处理 | 是否重建数据 |
|---|---|---|
| 旧训练器拒绝受限导数或 NaN 占位 | Chat 修复 mixed supervision／mask 路径，Work 保留原有效标签 | 否 |
| 仅十矩行无法训练 | Chat 验证 derivative-off 训练与任务缺失语义 | 否 |
| query 多项式吻合，导数因坐标变换不吻合 | 明确 Jacobian／basis 链式法则；若标签本身正确，在适配器修正 | 通常不需要；保留变换记录 |
| 实际教师标签错误或有效标志错误 | Work 追溯教师，修正受影响查询并建立新版本 | 只处理确认受影响项 |
| 教师积分域与 RLE 体素域不同 | 量化表示差异，明确学习目标；必要时生成匹配域标签 | 按证据定范围，不默认全库重做 |
| 外部 SDF 尚未接入 | 首跑明确使用 RLE 派生特征；外部 SDF 单独实验 | 否 |
| 几何／标签文件 hash 与冻结索引不同 | 暂停该版本消费，定位文件变更，重新审核和绑定 | 不通过改 hash 绕过；按变更范围处理 |
| 独立开发有效监督为零 | Work 优先处理独立候选；pilot 仅作拟合诊断 | 不重建已合格训练数据 |
| GPU OOM、每步显存增长或缓存陈旧 | Chat 调整实际训练批次／分块／缓存，保持数据与比较协议 | 否 |
| pilot loss 下降但 M69 优化失败 | 独立检查约束、Jacobian 尾部、oracle 与校正策略 | 不据 loss 单独决定重标或放行 |

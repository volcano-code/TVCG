## 二、本轮固定的架构与证据边界

| 层 | 本轮执行约定 |
|---|---|
| 材料 | 真实原网格构建的守恒 RLE/边界正权材料；支持 native256/512/1024，先用合格 256，按需要做独立 512/1024 对照 |
| 编码 | 一次共享 P-CRAFT / U-FNO，默认 64³+128³ 上下文；局部矩特征、质量加权摘要、有限切面交叉 attention |
| 查询 | 有限、有向、带端盖的原生操作数；32³/64³ 粗边界层级；完整保留/剔除节点使用材料解析矩 |
| 响应 | 正权原子上的有界 `compact_warp`；目标每粗节点不超过 32 点，压缩失败保留确定性回退 |
| 导数 | 从最终同一十矩取得完整一阶 J，包括运动、坐标、attention 与混合门控链；资格事件不伪装成有效导数 |
| 精度控制 | 粗细差异作为经验指示，光滑混合和必要细规则；指示器不是已证明的误差上界 |
| 最终求解 | 复用原生 solver，神经提案/原生校正分别计费，最终由原网格独立验收 |

现有软件可训练、可比较并有部署桥接；**真实 GPU 精度、网络相对强确定性方法的净收益、完整求解加速仍需实测**。当前不包含 GPU 并行完整多起点、新流形求解器或固定次数的原生精修保证。

材料分辨率、编码分辨率与查询层级是三件不同的事。native512/1024 输入不要求每次查询遍历其全体体素，也不证明高分材料能自动消除局部响应误差。

### 4.2 三类“通过”不能混写

- [ ] 完整材料十矩 `1e-8`：检查静态材料/固定壳与独立原网格的一致性，不代表部分切割精度。
- [ ] 模型 M/J/Jv 与来源/保留率保护：检查预测和轨迹局部可靠性，不代表终态原网格通过。
- [ ] 原生独立验收及完整求解耗时：检查实际任务质量和效率，不使用模型自身残差代替。

同面换侧互补只针对同一个有限操作数；含固定材料时总矩之和为 `2*M_fixed + M_full_editable`。不重新引入独立 ±c 构面的强制互补或未经教师验证的系数尺度不变性。

## 五、训练与决策口径

首轮使用 [configs/training_pilot.json](configs/training_pilot.json)：seed `830251`、Adam `3e-5`、batch 1、M/J 权重各 1、辅助物理损失 0、312 次真实更新、最多 624 attempts；FP32 网络/FP64 矩聚合，AMP 关闭。默认从合格 native256 开始，上下文保持 64³+128³。

| 关口 | 通过条件 | 不能据此宣称 |
|---|---|---|
| G0：短 Pilot | 材料/教师身份、有效标签、求导与数值、真实 GPU 更新/恢复正确 | 已达最终精度或论文加速 |
| G1：下一阶段有界预算 | 本轮来源宏平均原始 M RMSE 改善至少 5%；有分母的预登记保护项至多 +5%；无已确证未修复表示瓶颈，且诊断/剖析支持继续 | 缺标签的 R8/Full-J 已通过；独立泛化已证明 |
| G2：正式大预算长训 | G1，加声明范围内的原网格合格解、相对同输入基线的可信收益、明确预算/停止规则 | 所有来源、全部初值必然成功 |
| G3：部署及论文结论 | 封存独立来源，同初值/目标/约束/停止/线搜索，原网格验收、目标质量、全成本、强对照与统计证据 | 仅凭查询速度或软件回归即可晋级 |

历史 5% 与 +5% 是工程筛选，不能当作物理准确率或显著性。主指标保留 raw source-macro，同时另报物理尺度归一化结果；缺分母写证据不足。完整 50 种子和论文消融安排在最终推广阶段，不用它们无限阻塞 G0。

`--resume` 保持全部配置和原预算；预算跑完后不会自动追加更新。新预算/新快照另立阶段，按显式模块语义初始化并重新建立 optimizer；报告各阶段及累计计算。`--mode long` 不等于物理或训练晋级。

## 六、本轮必须补出的研发证据

1. **表示 oracle**：同粗前沿、同材料/原子/support 上的有界十矩拟合，保存可行解、原/对偶界和 gap。拟合好只说明放松表示存在好解，不能推出当前头可达、跨查询可学或 J 正确。
2. **强确定性基线**：现有 fine GL2/GL3 是平滑响应参考；新增同粗零修正与可控精度局部积分，公平计其真实成本，不强行给无学习臂添加编码器。
3. **同点 M/J 四组合**：复现全原生，再分别替换 M 或 J；固定点验收归因与下一步方向/线搜索归因分开。
4. **学习净收益与消融**：E0、同粗零修正、训练后和 fine/强基线分开；仅局部几何与加入全局/attention 对照，避免把改表示或多曝光的收益写成神经贡献。
5. **原生端到端**：直接替代和混合路线分别记录，失败与校正全计费；冷启动和缓存复用分别统计。当前不预设毫秒耗时、固定精修步数或加速倍数。

以上是检验方法价值的必需证据，不是保证发表或保证网络胜过确定性方法的承诺。若确定性方法在同等物理质量下更快，工程路线应保留它，并据实调整神经部分的研究定位。

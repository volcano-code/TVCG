## 1. 当前判断与并行关系

- **先复用和核对现有 TRELLIS 库，不默认重新生成一批模型。**几何库存、当前语义下的合格标签、Pilot 入选清单和实际训练曝光是不同集合。
- Work A 负责几何/材料/教师与标签资格；Work B 负责训练选样请求、导出配置、加载清单与实际曝光。两端共同解释“为什么这轮只有 4 件”，不能由任一端猜测未入选原因。
- 历史清单明确要求先交可用于短 Pilot 的冻结子集，但目前没有完整的本轮原始选样请求和逐项未入选回执。因此，**有意限制 Pilot 范围是待核实的解释，不能直接断言其余资产不合格，也不能直接断言全部都已可训练**。
- 用户已确认旧配置的隔夜训练失败；最新看到的是 E5 汇总，最终完成轮次、最终更新数和终止原因仍须原始日志核实。
- 不把 E5 汇总自动解释为最终轮次；不把旧三轮的 819 次更新写成整次隔夜训练的最终更新数。
- Work A 的目标是冻结证据、对账库存与选择范围、补齐确证缺口；更多数据本身不构成模型改进证据。
- **Work A 不阻塞 Work B 用已有 4 件训练几何进行路径诊断、固定训练探针与梯度审计。**先交旧快照资产，库存核对和补标并行推进。
- 优先级依次为 A0 冻结已入选身份、A1 现有库存及选择原因对账、A2 首批轨迹查询、A3 导数资格。无需等待全库重新处理后才交接。
- 暂不要求全面升级至 512/1024；高分辨率或连续材料对照仅在具体误差证据支持时另立受控实验。

## 4. A2：首批约 24 条合格轨迹查询

- [ ] 先查现有轨迹/标签是否已覆盖所需位置；能复用即复用，只有确实缺失才重新运行原生教师。

- [ ] 覆盖初值、一般迭代、接近收敛的末段、通过原生验收的终点与合法邻域；重点补齐当前末段/终点空白。
- [ ] 末段和终点同时覆盖中保留与高保留；保留近零及低保留比例对照，不删除表现差的高保留难例。
- [ ] 固定并记录保留比例分箱边界与计算依据；样本不足的格子显式报零，不看结果后重画分箱。
- [ ] 每条查询绑定 `trajectory_id`、原生任务、迭代序号、阶段、保留比例、终点验收凭据与参数邻域位置。
- [ ] 轨迹成功须由原网格上的原生验收确认；不能用代理模型残差、小梯度或确定性积分收敛替代物理成功。
- [ ] 邻域查询记录扰动方向、原始参数尺度与距离；原生终点成功不自动证明其每个邻域查询或导数均有资格。

- [ ] 先交可核验的部分批次及缺口表；不为凑足 24 条纳入来源不明、未验收或不合格标签。

## 9. 验收通过条件与停止规则

- [ ] 旧身份数量可由逐条记录重算，checkpoint 与原 manifest/binding 可核对；最终轮次未知时明确未知，不以估算填充。
- [ ] 各快照的库存、当前资格、选择范围与实际曝光分别可重算；跨快照对应关系有证据，不把不同角色或版本强行拼为一个分母。
- [ ] 能回答“4 件是如何选出的”：若原选择证据未找到，明确该项未完成；不因此阻塞旧权重诊断，也不能猜测全部未入选资产不合格。
- [ ] 若旧选择意图无法恢复但旧身份与实际曝光可核对，将历史未知单列；它不单独阻塞一个选样明确、身份/资格完整且另立阶段的新覆盖实验。
- [ ] 已核实的未入选原因可追踪，未知项显式保留；Moment-only 合法记录未因无 J 被整批剔除，可复用数据没有因遗漏而重复生成或补标。
- [ ] 轨迹查询能够定位原生成功凭据，覆盖表明确末段/终点、中高保留与低比例对照的实际有效分母。
- [ ] 所有宣称合格的 R8/Full-J 均有完整资格收据；缺失导数不影响独立 M 的合法使用，也不进入 J 统计。
- [ ] 物理语义、固定材料、来源隔离、旧开发身份和新阶段 binding 校验全部有证据；任何一项不符，该记录不得准入。
- [ ] 缺少来源、轨迹、资格或原网格验收分母时，标注“证据不足/未通过该项”，不得将未覆盖格子、缺文件或少量样例宣称整体通过。
- [ ] 数据交付通过只表示资产、身份与资格达到本清单要求；模型改善仍由 Work B 的配对实测和原部署协议决定。

## 10. 给 Work B 的即时交接

第一批先交旧 run 冻结包、现有库存摘要和选择原因对账；Work B 可据原绑定立即运行已有权重诊断。可复用库存和定向新增轨迹/导数随后分批交付。
若 Work B 发现某条旧数据身份或教师不一致，先标记并追溯；保持旧开发分母可复现，修订资产另立阶段，不静默替换。
每次回传说明“已有多少、当前可用多少、本轮为何选这些、实际用了多少、真正还缺什么、是否需要新阶段”。**对现有 4 件的训练退化与全库规模是否足够分别作答**；不写“数据增加后模型必然修复”。

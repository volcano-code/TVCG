# HENMO V1+ 规划落实审计

审计日期：2026-11-27。研究分支：`research/henmo-v1plus`。基于已发布 V2.4 的 `50706a45580e8be7a70e4ed22a7b13c56c67730e` 构建。

## 审计结论

**本轮核心架构和配套训练、比较、部署接口已实现，并通过软件集成验证；尚不能把“全部规划的科学与性能效果”判为已完成。** 当前可交给 Work 进行真实数据短训及原生闭环实验。GPU 多起点完整轨迹并行仍是明确未实现的可选优化，不能写成已经完成。

这里按代码、软件验证、真实物理证据三个层次核对。未获取生产数据或 GPU 实测的项目保持未验证，不以 CPU 合成测试替代。

## 2. 本轮发现并修复的具体问题

1. **压缩点与窄带不匹配**：少量粗积分点可能全部落在原生体素宽的响应带外，导致网络梯度为零。现在粗支撑与节点直径匹配，细积分保持原生带宽，并有复现旧零活跃点失败的回归。较宽支撑产生的近似偏差仍需实测。
2. **“粗细对照”先付全量细积分费用**：子级 probe 改为粗压缩规则，父层接受时不展开细 GL3。回归检查 fine evaluation 为 0。
3. **形式上 batch、实际上逐节点网络调用**：现在初始 frontier 与直接子层 frontier 各自合并同带宽点集。微型自适应回归中整个两层 probe 为两次实际网络调用，不能据此外推生产耗时。
4. **混合输出遗漏门控导数的风险**：完整链式项保留，并与独立自动微分核对；J 差只作资格判断。
5. **缓存与训练图生命周期**：包含 buffer 与局部投影版本；缓存 tensor 修改、权重更新、已消费图和 inference tensor 均有检查。
6. **材料重复解压**：prepared 路径改为按已校验材料资产 SHA/identity 共享，不因每条查询目录不同重新加载。
7. **复数谱权重被实数转换损坏**：CLI 改为先转设备再调用 float/double；部署/比较拒绝静默 dtype 转换。
8. **Moment-only 接口误拒绝**：只要值合法，允许返回待原生验收的 Moment-only 提案；完整 Newton 回调仍要求合格 J。
9. **新旧协议和报告混淆**：训练新空目录；起始 incumbent 单独标记；退化权重不冒充最佳新候选；精确 resume 与新阶段初始化严格区分。
10. **不公平查询计时**：构面准备与输出回 CPU 进入各比较臂时间，共享 hierarchy 与候选 encode 单列，失败行不删去。
11. **任务设置绑定不完整**：原生迭代/线搜索等完整设置进入摘要；设置变化使注册失效。

## 3. 实际执行的验证

最终集成测试选择了全部新增 HENMO 测试及受影响的旧训练、导出、V2.4 注意力回归：

```text
169 passed, 2 warnings in 24.81 seconds
```

两个 warning 来自现有 pytest 插件弃用与配置项，不是模型数值失败。该测试数不是整个仓库全部历史测试的总数。

此后仅将 CLI 初始化回执的来源标签由默认 E16 改为 `explicit_cli_initialization`，避免 HENMO 后续阶段被误标为 E16；对应迁移/CLI 定向回归另有 **4 passed（3.35 秒）**。没有借此宣称多出四项独立全套覆盖。

原始 JUnit 报告：`evidence/software_tests.xml`。可复现命令与摘要：`evidence/software_summary.json`。模型参数清单：`evidence/parameter_inventory.json`。

独立 CLI smoke：主线完成 **2 次真实 M+J 更新**，从第一步 checkpoint 再执行第二步，全部权重逐值相等；恢复分支是额外一次 optimizer 执行，逻辑终点仍为 step2。报告在 `evidence/smoke.json`，使用 CPU 解析合成 fixture，明确 `physics_promotion=false` 与 `gpu_speedup_proven=false`。临时 fixture checkpoint 不作为生产权重发布。

另有实际 side512 合成材料从导出清单进入 CLI 审计和一次真实参数更新的回归，确认不是只检查 JSON 配置值。它没有运行真实高分面条，也没有在 RTX 5090 上训练。

## 4. 当前配置可证明什么

默认候选的实际参数 inventory 见 JSON：共享 encoder 403394 个 tensor elements，材料摘要注意力 37248，局部几何投影 17472，新边界头 15745。由于谱参数含复数，real scalar equivalents 另列，不用不同计数口径虚报压缩率。参数少不等于推理必快，128³ 激活、有限面查询与细化开销仍须实测。

静态材料聚合和正权压缩高精度重现完整十矩，不证明任意部分切割矩；父子一致不证明真实误差小；有界保留率不证明最终驻点正确；合成导数检查不证明生产 Full-J/R8 标签已补齐；原生最终验收接口不证明已经得到一个合格新陀螺。

## 5. 后续的明确验收边界

Work A 交付可读的正式材料/教师快照与缺失覆盖；Work B 完成目标 GPU 的联合更新、同输入确定性对照、同轨迹归因和原网格求解配对。满足物理质量与完整时间证据后再扩大训练。

本轮没有把任何新模型设置为生产默认，没有合并到默认分支，没有把旧已训练 checkpoint 改名为 HENMO 已训练权重。发布的是可审查、可训练、可复现的研究分支。

# Compact PINO：局部响应升级与快速训练入口

本目录将已发布的守恒算子接到一套可复算的短程对照：保留 256³ 材料表示、共享多尺度 P-CRAFT / U-FNO 与 Token16，新增可在外带宽内部达到饱和的局部响应，冻结静态编码部分，只训练局部响应参数。

**本次交付的是架构改造和可执行训练工具。真实几何上的精度、原生 Newton 成功率及取得合格解的总耗时，仍须由 Work 端实验验证。此前物理 NO-GO 不因软件测试通过而自动解除。**

执行顺序、输入凭据与本地指令见 [WORK_HANDOFF.md](WORK_HANDOFF.md)；长训练准入及持续运行说明见 [LONG_TRAINING.md](LONG_TRAINING.md)。

## 2. 为什么替换局部响应

旧响应使用基础平滑保留率 \(p\)，再施加有界加法修正：

\[
r=p+p(1-p)a,\qquad
a=\tfrac12[b+t(2p-1)],\qquad |b|,|t|\le1.
\]

当 \(p\in[0.5,1)\) 时，旧形式满足 \(r\le p+p^2(1-p)<1\)。例如，基础保留率为 0.9 的积分点，旧头最多给出约 0.981。若真实切割完整保留该点，这个局部限制无法只靠增加网络参数消除。

这是**逐点表达范围的限制**。它不等于整件物体必然有固定百分比的质量误差，也不证明此前所有失败均由它造成；不同位置的误差可能在十矩积分中抵消。本次改造扩大该局部响应的表达范围，保留独立对照测量其实际作用。

## 3. 新响应公式及证明范围

令 \(H>0\) 为准备 stencil 时使用的固定外半带宽，\(d\) 为有限切割面的有向距离，内部取正，\(s=\operatorname{clamp}(d/H,-1,1)\)。两输出网络接收积分点位置与**不依赖切割参数的静态几何特征**，输出 \(z_u,z_v\)。定义：

\[
u=\tanh z_u,\quad v=\tanh z_v,\quad
a=\exp(\log3\,u)-1,\quad \delta=\tfrac14v,
\]

\[
y=s+\delta(1-s^2),\qquad
q=y[1+a(1-y^2)],\qquad t=\operatorname{clamp}(q,-1,1).
\]

基础三次函数为：

\[
P(t)=\tau^2(3-2\tau),\qquad \tau=(t+1)/2.
\]

同一切割面的两种操作使用：

\[
r_{\cap}=P(t),\qquad r_{\setminus}=P(-t).
\]

差集直接计算小的一侧，避免在保留率接近 1 时用 `1 - r` 消去微小质量。实现使用 `expm1` 和因式分解的多项式，降低零锐化参数和饱和端点附近的消减误差。

### 3.1 保证了什么

- **有界**：两种保留率均在 \([0,1]\) 内。
- **同面互补**：\(r_{\cap}+r_{\setminus}=1\)。这只针对同一个有限切割面，不能推广成两次独立构造反号切割面的强制互补。
- **最终保留率对距离单调**：\(dy/ds=1-2\delta s\ge1/2\)。当 \(a\le1/2\) 时第二个变换也单调；当 \(a>1/2\) 时，\(q\) 可以在靠近端点处回落，但该回落区始终落在 \(|q|\ge1\) 的饱和区。最终的 \(P(\operatorname{clamp}q)\) 仍单调。
- **\(C^1\) 饱和连接**：\(P'(\pm1)=0\)，内部饱和点和外带宽边界的响应及一阶导数连续。
- **允许带内达到 0 或 1**：新头可以表达旧头上述反例所不能表达的完整逐点保留。
- **零输出有明确基线**：末层权重和偏置为零时，\(a=\delta=0\)，得到原无学习平滑 cubic。

这里不能声称 \(q\) 在全区间单调；单调性属于**经过饱和之后的最终保留率**。

### 3.2 同一响应的解析导数

在静态特征不依赖切割参数的前提下：

\[
\frac{\partial r}{\partial s}
=\pm\frac34(1-t)(1+t)
\,[1+a(1-3y^2)]\,(1-2\delta s).
\]

再乘 \(1/H\) 与原生面片顶点运动产生的距离导数，积分得到 J。正负号分别对应交集与差集。所有系数计算保留参数梯度图，因此 J 损失仍可更新响应参数；原来的自动微分路径保留为独立核对入口。

若以后让局部系数依赖查询曲率、切割方向或其他随系数变化的输入，必须补入这些输入的导数。当前静态特征假设不能被悄悄沿用。

### 3.3 没有保证什么

零输出基线是**平滑保留率的数值积分**，不是精确网格布尔。增加锐化可以减少部分平滑偏差，也可能让现有积分点不足以解析更窄的过渡，造成 Moment 改善而 J/Jv 变差。

因此，响应表达范围扩大、积分阶数提高、原生硬切割精度提高，是三个需要分别验证的结论。本次没有证明三者等价，也没有证明新头达到原生终点容差。

## 4. 守恒端点与一般切割误差必须分开

十矩始终由同一个物理响应计算：

\[
\widehat M=M_{\mathrm{fixed}}+\sum_\ell w_\ell r_\ell\phi(x_\ell),
\qquad w_\ell>0,
\]

其中十个基函数顺序沿用 `1,x,y,z,xx,yy,zz,yz,xz,xy`。

完整保留或完整剔除的保守几何分类、固定材料只加入一次，以及同一材料的完整十矩审计，都继续保留。整块跳过仍基于原外带宽的几何界；不会因为网络对某个点给出饱和值，就新增未经证明的整块跳过。

对于同一有限 operand，可编辑材料两种操作的十矩相加应恢复完整可编辑材料。若两次结果都包含相同固定材料，则：

\[
M_{\cap}+M_{\setminus}=2M_{\mathrm{fixed}}+M_{\mathrm{editable,full}}.
\]

这类守恒检查不替代一般切割的原生十矩比较。完整材料审计通过，只约束完整材料的积分；切过边界后的空间分配仍需独立检验。

## 5. 两臂试验怎样保证可比

| 配置项 | A_old_response | B_monotone_response |
|---|---|---|
| 响应形式 | `bounded_cubic` | `monotone_warp` |
| 编码器、attention、响应隐藏层初值 | 相同 | 相同 |
| 响应末层 | 清零 | 清零 |
| 初始数值响应 | 无学习 cubic | 相同无学习 cubic |
| 训练范围 | 仅 response | 仅 response |
| 数据、查询曝光次序、积分规则 | 共享冻结配置 | 相同 |
| 学习率、损失系数和候选选择规则 | 共享冻结配置 | 相同 |

两臂均包含物理监督。A/B 的用途是隔离响应形式的差异，不再把不同数据、不同积分规则和不同损失同时混成一次架构比较。

校准程序检查两臂的初始张量摘要一致，以及所选训练查询的初始 M/J 一致。每个模型既与本轮共同 E0 比较，也应单列旧训练模型和无学习积分器的绝对误差，避免只因改变 E0 而产生虚假的相对改善。

如果积分规则需要从 tetra4 改为 gl2/gl3，应在揭晓新候选结果前确定，并对两臂共同使用。积分规则的对照可使用既有 [precision 工具](../precision/README.md)。

## 6. 冻结编码与缓存的梯度策略

`training_scope='response'` 会冻结 `shared_encoder` 与 `geometry_attention` 的参数，同时保持其子模块为 `eval()`，避免运行 buffer 继续变化。

跨查询、跨 response 更新的缓存只保存**没有计算图、尚未经过 response 首层投影的静态 token 表**。response 首层的 \(W_hh\) 每次 forward 重新计算，保留对该首层的梯度，不把它缓存到下一次更新。

缓存检查冻结参数、buffer、模块模式、材料身份与特征表内容版本。权重载入、参数或 buffer 变化、设备/数据类型转换会失效；缓存容量与条目数有限制。对需要全部参数训练的旧路径，已经消耗的训练图不能再次复用。

末层严格零初始化意味着：**第一次更新先学习末层，隐藏层梯度在这一刻为零是预期结果。** 末层更新后，后续 J/M/物理损失才会把梯度传入响应隐藏层。这不等同于梯度断开。被冻结的几何编码器在本轮始终不更新。

这些改造减少重复编码的机会，但实际速度仍需包含数据读取、构面、缓存、推理、导数和验收进行测量；不能仅凭缓存命中率宣称获得端到端加速。

## 7. 初始权重与 checkpoint 兼容

旧构造默认保持 `response_type='bounded_cubic'`、`response_zero_init=False` 和 `training_scope='all'`。旧头的参数布局与默认数学语义不变。

新头仍是两输出，但这两个输出的含义已经改变，不能把旧末层权重直接当作新锐化和位移系数。迁移必须显式使用 `geometry_and_hidden`：严格验证 canonical runner checkpoint 的 SHA、配置、键、形状、数据类型和有限性，保留可继承参数，清零：

```text
response.local.2.weight
response.local.2.bias
```

这是新试验的初始化，包含新的 optimizer、采样和 RNG 状态；不属于旧训练的精确续训。新试验自己的断点恢复则保留已学习的末层、optimizer、曝光游标和协议身份，不能再次清零。

`calibrate` 用相同迁移为两臂建立共同 E0；`probe` 载入已训练 checkpoint，明确**不重置末层**。工具拒绝未适配的私有权重格式，不猜测键映射。

## 8. 工具职责与顺序

| 模块 | 职责 | 不代表什么 |
|---|---|---|
| `smoke` | 合成材料上的实际更新、冻结状态及恢复检查 | 不代表真实几何物理验收 |
| `calibrate` | 仅训练来源的 E0 分项梯度与共同物理系数校准 | 不生成训练晋级或原生合格凭据 |
| `prepare` | 核对已准入数据、合法性证据与校准结果，冻结两臂配置、曝光日程和新预注册 | 不生成新教师或替 Work 独立复算几何合法性 |
| `authorize` | 将已有用户授权与外部 correctness 证据绑定到具体配置和预算 | 不制造 correctness PASS 或模型 GO |
| `run` | 核对 bundle 各项身份，执行指定臂及精确恢复 | 不自动越过长训练准入 |
| `probe` | 对已训练 checkpoint 诊断训练来源上的分项梯度、冲突与实际系数份额 | 不更新权重、不重新校准训练协议 |
| `runtime` | 从真实训练日志估计后续计算预算 | 不是合格解加速比或统计置信区间 |

### 8.1 无更新梯度校准

```bash
python -m experiments.compact_pino_v21.rapid_training.calibrate \
  --manifest /absolute/training_manifest.json \
  --mode trial \
  --cohort /absolute/cohort.json \
  --full-cell-rule gl2 \
  --device cuda:0 \
  --seed 830251 \
  --max-records 12 \
  --output /absolute/calibration.json
```

如继承已有 canonical checkpoint，还须同时提供 `--initial-weights` 和 `--initial-weights-sha256`。`--output` 是新 JSON 文件，已有文件拒绝覆盖。

严格 manifest loader 完成来源隔离和标签资格检查后，校准只从 cohort 中选取正权重、物理监督有效的训练记录，按来源 round-robin。开发、盲测或未知 ID 不进入校准。`--max-records` 必须足以覆盖这些合格来源。

每条查询只建立一次预测图，分别计算 M/J/R/C 的独立损失及 response 参数梯度。每项使用自己的有效分母；缺少合格 J 时记录分母 0 和原因，不补零标签。

本轮固定 \(\lambda_J=1\)。共同 \(\lambda_R,\lambda_C\) 取两臂训练查询中正且有限的 \(0.1\|g_M+g_J\|/\|g_R\|\)、\(0.1\|g_M+g_J\|/\|g_C\|\) 比值的中位数。报告逐条实际份额；**中位数校准不保证每条查询或后续每次更新都恰好占 10%。**

校准会验证参数与 buffer 未改变、`.grad` 未积累，输出 `parameter_updates=0`。它不使用开发预测选择系数。

### 8.2 已训练 checkpoint 的漂移诊断

```bash
python -m experiments.compact_pino_v21.rapid_training.probe \
  --manifest /absolute/training_manifest.json \
  --mode trial \
  --cohort /absolute/cohort.json \
  --checkpoint-receipt /absolute/run/best.json \
  --device cuda:0 \
  --max-records 12 \
  --output /absolute/gradient_probe_step104.json
```

`last.json` 也可作为入口。工具按 receipt 的路径和 SHA 安全载入 checkpoint，关闭推理缓存，只开启 response 梯度，不建立 optimizer，不重置输出层。

报告包含原始 M/J/R/C 梯度范数、余弦，以及按该 checkpoint 保存的损失系数计算的加权项和联合梯度。联合范数通过向量内积计算，不能用各项范数直接相加。该诊断可以判断后续误差恶化时是否出现梯度冲突或比例变化，但不会自动更改损失系数。

CUDA 确定性运行须按交接清单在进程启动前配置 `CUBLAS_WORKSPACE_CONFIG`。完整实测软件回执应保留运行设备和依赖版本。

## 9. 数据、曝光与筛选边界

首批真实 cohort 按四件训练几何、24 条独立查询组织：每件 1 个原生验收终点、2 个合法末段状态、2 个非平凡高保留状态、1 个普通合法状态。目标、支点、固定材料和坐标必须绑定同一任务。`prepare` 检查 Work 提供的声明及原始证据资产身份，不能把这一步称为重新完成了独立网格验收。

共享日程在训练前冻结，候选还须满足最低已提交物理监督曝光。计划查询次数不等于真实参数更新次数；无活动材料等跳过行为不会被记作成功更新。日程按尝试曝光消耗，不会为跳过记录自动循环补数。

原 5% 主指标改善线、1.05 保护线、来源隔离和有效导数资格继续使用。缺 Full J 等资格应显示证据不足。新增训练 cohort 不移动严格开发来源，额外开发诊断也不替代原固定开发集合。

下一阶段若要调整训练范围、数据、积分规则、权重或选模位置，应先冻结新的试验配置。不能看过候选结果后修改门槛，再把同一结果报告为原协议通过。

## 10. 当前结论和仍需取得的证据

本次软件可检查的结论包括：旧默认行为兼容、新头有界且最终响应单调、端点一阶连续、解析与 AD/有限差分一致、J 损失保留参数梯度、冻结特征可跨 response 更新安全复用，以及校准和恢复的身份绑定。

原生校正与最终原网格验收继续保留。软件通过、短训完成、目标值接近原生、或者平均 Moment 改善，都不能单独替代原生最优性残差通过。

## 2. 工作分配与执行顺序

| 顺序 | 责任方 | 操作 | 完成后交什么 |
|---|---|---|---|
| 0 | Work B | 安全停止旧运行，冻结实际最后状态 | 停止回执、checkpoint 清单、运行身份 |
| 1 | Work B | 隔离检出 R3，核对原权重/配置/快照；做软件和数据预检 | 代码/环境记录、预检结果、数据审计 |
| 2 | Work B | 同权重重放；先少量异常点和正常对照，再做一次完整开发比较 | E0、E4、E5或最终失败代表点的配对结果 |
| 3 | Work B | 八路径与训练侧 M/J 分项梯度；只读，不更新参数 | 路径、梯度 JSON 与明确的定位结论 |
| 并行 P0 | Work A + Work B | A 盘点既有库存、材料与 M/J 资格；B 追溯四件选样/导出范围，核对实际加载与曝光 | 联合签收的库存、入选/未入选原因与实际曝光对账 |
| 并行 P0 | Work A | 从既有来源优先补末段/终点、跨来源曲面 R8/Full-J；M/J 分别准入 | 数据侧清单规定的覆盖与资格凭据 |
| 4 | Work B | 明确一个修正因素后，运行同起点 Moment-only / joint 各 128 步 | 两臂原始产物和各指标，不自动晋级 |
| 条件触发 | Work A + Work B | 基本可学习性确认后，从已就绪库存另建代表性来源覆盖 Pilot，不与损失/路径修改混杂 | 新阶段身份、预登记预算和配对覆盖实验 |
| 5 | Work B | 复查原部署路径与原生终点；再决定正式增加训练预算 | 同口径精度、真实合格解与完整耗时证据 |

**Work B 的已有权重诊断不等待 Work A 完成扩容。单张 5090 D 上不并行运行旧训练、新训练与性能计时；数据整理和日志分析可以并行，CPU 密集补标应限制资源争用。**

优先复用现有库存。只有证明现有资产缺少所需独立来源或几何类型时，才追加 TRELLIS 生成；原网格已经存在而标签尚未就绪时，优先完成加工和补标。

完整参数、路径准备和产物检查见 [Work B 执行清单](WORK_B_EXECUTION_R3_2026-11-28.md)。当前真实存在的入口是：

```text
python -m experiments.henmo_v1plus.cli audit-data ...

python -m experiments.henmo_v1plus.cli compare ...
```

上面是入口索引，不是可直接粘贴执行的完整命令。不要把 `...` 当参数。Work B 文件提供完整模板。

当前没有 `stop`、`benchmark`、`promote`、`solve` 子命令，也没有根据 5% 指标自动早停或晋级的控制器。停止旧任务使用 Work 已有进程管理；原生求解使用现有已注册 solver callback。不得虚构一条验收命令，或将 CLI 退出 0 当作物理通过。

## 4. 每阶段的通过条件

| 阶段 | 允许下一步的条件 | 不能据此声称 |
|---|---|---|
| 软件与身份 | 预检通过；源权重、dtype、配置、快照、查询身份核对一致 | 真实几何精度合格 |
| 数值保持 | 同权重同输入的原始 M/J 在事先登记的浮点容差内一致；完整开发覆盖核对无缺失 | 已修复旧模型退化 |
| 归因 | 已确认数据/教师口径一致，失败被复现，并有一个可检验的修正假设 | 已定位所有几何的唯一根因 |
| 128 步短筛选 | 预算完整、记录齐全；能区分 M-only、joint 与无学习参考的作用 | 已满足长训或原生优化条件 |
| 来源覆盖短实验 | 数据身份可信、基本训练可学习性已检查；只改变覆盖因素，固定预算与源权重初始化规则 | 旧四件不足是唯一根因，或新增数据保证成功 |
| 正式增加训练预算 | 在声明部署路径检查原 5% Moment 主线及各保护项；另有基线、分来源和终点证据 | 仅凭 coarse 诊断即可部署 |
| 最终部署/论文 | 独立来源、冻结初值、同质量原网格验收与全成本比较 | 单查询耗时等于合格解加速 |

原已登记门槛继续保留：来源宏平均原始 Moment 相对声明的 E0 至少下降 5%，各预登记保护误差至多为对应 E0 的 1.05 倍。若沿用原 E0 `2.5324920350532497e-7`，Moment 线是 `2.405867433300587e-7`；新阶段另有自己的 E0 时必须同时列出，不能用较差的 E5 人为降低比较难度。Full-J、低保留或终点缺有效分母时写“证据不足”，不能签发该项通过。

这些精度门槛不阻塞无更新诊断，也不要求失败旧权重先合格才能进行 128 步定位实验。通过线不随结果事后放宽。

新增来源的有限 Pilot 用于检验覆盖假设，也不要求旧四件先过正式 5% 线；但须先确认身份、教师、基本训练过程可信，并预先冻结单因素和预算。不能将其直接延长成正式长训。
旧四件选择意图若无法恢复，应保留“未知”；在旧实际身份与曝光可核对、新阶段选样与资格明确的前提下，这个历史缺口不单独阻塞新的受控实验。

### 归因后如何选下一步

| 结果 | 下一步 |
|---|---|
| 很多现有模型已具备当前材料与 M 标签，只是未选入 Pilot | 新阶段从已有库存扩大代表性来源；不重复生成，也不把未入选称为不合格 |
| 原网格已有，当前材料/教师标签/资产可读性未就绪 | 优先完成这些环节；M、R3、R8、Full-J 分别标注资格 |
| 四件的具体选择原因仍无原始证据 | 写“选择原因待核实”；不编造其余资产被排除的理由 |
| 固定训练探针和开发都恶化 | 先查教师、尺度、最终响应、训练/评估路径和梯度；扩充几何不能替代这一步 |
| 同路径训练误差改善、留出来源恶化 | 将采样覆盖与泛化作为下一轮可检验假设；仅开发恶化不够证明过拟合 |
| coarse 好而 adaptive 差 | 查层级/门控/细化与最终响应，先解决实际部署路径问题 |
| 学习模型只优于自身起点，仍不如确定性参考 | 继续核实学习分支净收益；不宣称网络已优于无学习路线 |

新数据必须使用新阶段 manifest、合法初始化/迁移和新 E0；不得偷换旧数据文件、修改哈希或绕过 checkpoint binding。旧 222 条继续配对，新开发和封存盲测分别报告。

# Work A 交付清单 R2：HENMO V1+ 数据、教师与表示能力诊断

版本日期：2026-11-27。适用入口：本目录 `README.md`、`WORK_A_ACTION_GUIDE.md` 及当前 HENMO V1+ 实现。

**Work A 负责原始几何、材料、原生教师、来源隔离与有效性凭据；Work B 负责原子构建、oracle 拟合、确定性基线、模型训练和原生求解。** 本轮先交付能够支持短 Pilot 和同查询归因的冻结子集，再按实测缺口补数。全部数据升分辨率、全部论文基线完成、所有导数类别齐备，均不作为启动这一轮有范围声明的短训的统一前置条件。

## 一、P0 执行顺序与交接

| 顺序 | 输入 | Work A 动作 | 输出及验收 |

| A0 冻结身份 | 已获准快照、旧开发 222 条、原生版本 | 冻结查询、原网格、材料、TaskSpec、标签与来源；新资料另建 snapshot | 原身份可追溯，不覆盖旧报告；训练/开发来源无交叉 |
| A1 准入材料 | 已有 native256 材料与原网格 | 校验完整可编辑材料、固定材料十矩及材料布局 | 完整十矩门槛通过；真实材料分辨率与配置一致 |
| A2 冻结查询教师 | 同一有限操作数及其运动、原生结果 | 校验最终十矩、有效导数与拒绝理由 | 每行可重算；无资格 J 有显式 mask |

## 二、材料与查询必须对齐的物理合同

### A1：材料基准

- [ ] 先复用**已获准且可复现的 native256 快照**。针对薄壁、空腔、细小结构及 oracle 暴露的表示误差，制作同原网格 native512 对照；native1024 只用于仍有必要的困难几何。不能靠改 JSON 的 side 或插值二值 RLE 生成“高分真值”。
- [ ] 固定原网格 SHA256、单位、密度、坐标变换、原点、pitch、材料构建版本及参数。改变分辨率或构建方法必须产生新材料身份。
- [ ] 完整内部 RLE 与边界部分体素互斥；区间不重叠；部分体素正权积分点在相应材料表示的有效空间内。保留中心在材料外的部分体素，不删去薄壁、孔洞与断连体。
- [ ] 固定材料独立存十矩，包含非零固定壳案例；固定与可编辑材料的分区不得重叠，也不得漏算。最终总矩只加一次固定材料。
- [ ] 用独立原网格积分核对全部十矩。以预先固定的正参考质量和长度构成 `m_ref * L^k` 尺度，完整可编辑材料与固定材料分别报告最差分量误差，双精度验收线为 `1e-8`。固定壳为零时检验确为零，不能除以零质量。

**这条 `1e-8` 是完整材料/固定壳表示准入门槛，不是每条部分切割的 Moment 门槛，更不是 Jacobian 准确率。** 部分切割的 M、J、Jv 精度由 Work B 使用同查询原生教师独立评估；训练前冻结的对应阈值不得被完整材料守恒结果替代。连通性和最终几何合法性由原网格验收，不能从十矩一致推出。

### A2：同一个有限切割及有效导数

- [ ] 原生教师、材料查询与候选评价绑定同一原网格、TaskSpec、有限有向且带端盖的操作数。保存顶点、面片、端盖身份、操作侧、构面版本、参数和坐标变换。
- [ ] 十矩顺序固定为 `[m,x,y,z,xx,yy,zz,yz,xz,xy]`。保存总原生十矩、固定十矩、完整可编辑十矩；可编辑保留比例由这些真实标签计算，不使用候选预测分档。
- [ ] 提供原始十系数或相应固定秩 chart、参数归一化、操作数顶点运动及有效邻域。Full-J、R3、R8 分别在各自合法参数空间验证；各类标签记录验证方法、多步长检查与异常原因。
- [ ] 变秩、相切、拓扑变化、最近面歧义等事件逐项登记；事件处可能仍有合法 M，但不能将不存在或未获资格的 J 填成零进入训练。保留事件两侧和拒绝样本用于诊断。
- [ ] 互补检查只作用于**同一有限操作数的交集与差集**。带固定材料时，两侧总十矩之和应为 `2*M_fixed + M_full_editable`。不得对两次独立反号构面强制互补，也不得未经部署教师验证强加系数尺度不变性。
- [ ] 真实布尔结果及切后矩仅作教师、校正和验收；不混入部署模型的查询输入。

## 三、本轮新增重点：交付 bounded-retention oracle 所需输入

目标是区分“固定原子表示本身装不下真值”和“表示有能力但网络尚未学到”。**Work A 不实现模型相关真值，不以候选输出反推标签，也不必先补齐每个粗节点的局部切割教师。** 现有合格的全局十矩即可开始全局表示能力诊断。

- [ ] 挑选覆盖当前失效类型的少量可复现实例，包括训练来源的中高保留近终点、薄壁/空腔、曲面切割，以及已登记的面条诊断点。选择依据及所属 split 明示；不得承诺某个固定样本数能代表全部几何。
- [ ] 每条冻结 `record_id` 对应完整材料资产、原网格、有限操作数、原生十矩、固定材料、坐标和标签凭据，不随候选改变。
- [ ] 向 Work B 提供可重建的 `PreparedMaterial` 输入。由 Work B 冻结并回传原子构建版本、层级配置、节点划分、局部到全局变换、正权位置/权重与哈希；Work A 核对它们来自同一材料身份。原子依赖编码器/权重时，必须额外冻结权重及重建配置，不能只报原子数量。
- [ ] 对一条查询，Work B 先冻结纯粗前沿 32/64 的层级、分类规则和可变保留率 support，再固定原子矩阵 `A`，仅对 support 内原子拟合 `0 ≤ r ≤ 1`。目标为原生全局十矩扣除固定材料、精确内部节点、当前 support 外 `r=1` 饱和原子及其他固定执行贡献；support 外的饱和原子不得释放为自由变量。若另行冻结 adaptive 分支、门控或混合状态，结论仅适用于该执行状态，不代表全部自适应查询。扣除项须给出可复算记录；Work A 保持原始教师不变，不把扣除后的中间量当作新的独立物理真值。
- [ ] 工作索引绑定同一 `query + material + teacher + atom configuration`。改变原子数、层级或材料后另建对照身份，不得挑选更易拟合的原子却称同表示的 oracle。

oracle 是自由保留率的乐观表示诊断。一个可行解的小残差只给出最优拟合误差的上界；只有可信对偶下界，或由经校验的最优性 gap 得到的下界，超过预先冻结的阈值并计入浮点及教师不确定性，才支持该固定表示不足的结论。未收敛应记为 `INCONCLUSIVE`。拟合良好也不证明当前 `compact_warp` 参数化可达、跨查询可学或 J 正确，更不是部署速度结果。依据上述证据再决定核查材料/原子支持/层级，或投入学习与定向补数；局部节点教师仅在确有定位收益时增加。

## 四、补标与来源隔离

| 数据角色 | 要做什么 | 使用边界 |
|---|---|---|
| train | 优先补原生成功轨迹的 `near_convergence`、`endpoint` 及有效邻域，尤其是中/高保留；再补跨来源抛物 R8、Full-J、低/近零对照 | 允许训练、训练侧阈值校准；终点必须有原生验收凭据 |
| development | 保留原 222 条配对集合；新终点、曲面、导数诊断单列，新正式集合另发 snapshot | 可选模，不能称未触碰盲测；来源不得与训练共享 |
| 封存独立来源 | 冻结原网格、来源、初值和评价任务，独立保存验证资产 | 不用于结构、带宽、采样或阈值选择；揭晓后记录使用历史 |

当前 loader 的训练数据角色是 `train/development`；`test/locked_test/fixed_benchmark/benchmark` 不可塞入同一训练 manifest。**独立验证包单独封存、交给 Work B 的部署/独立验收流程，不能把它重标为 development 来绕过加载限制。** 面条已参与诊断，只能继续作诊断，不能重新包装成独立证据。

- [ ] 输出 `source × surface_family × retention_bin × trajectory_stage × derivative_type` 覆盖；列出几何数、登记数、实际可加载 M、合格 R3/R8/Full-J 分母。训练曝光及更新数由 Work B 回填。
- [ ] `near_convergence`、`endpoint` 使用当前代码识别的精确阶段名称。普通迭代点不得写成“成功终点”；如后续启用残差标签，保留真实残差、固定乘子及既有资格，不能批量填零。
- [ ] 未取得 R8/Full-J 资格的行可作为合格 M-only 数据。缺少 R8 时可以做明确限定范围的短 Pilot，但不能宣称已验证 R8 监督、曲面导数泛化或对应完整求解范围。

## 五、实际命令与交付文件

在仓库根目录执行；下列绝对路径是须替换的示例。每次输出使用新目录。先导出单一 native256 快照：

```bash
python -m experiments.compact_pino_v21.p0_diagnostics.export_cases \
  --request /absolute/frozen/work_a_export_request.json \
  --allowed-native-resolutions 256 \
  --output /absolute/new/henmo_export256

python -m experiments.henmo_v1plus.cli audit-data \
  --manifest /absolute/new/henmo_export256/training_manifest.json \
  --config experiments/henmo_v1plus/configs/pilot256.json \
  --mode trial \
  --output /absolute/new/henmo_data_audit256.json
```

请求沿用已存在的 request、source authority 和 qualification 格式。`--synthetic-fixture` 仅属软件测试，不能用于真实数据准入。512 对照单独导出，分别使用 `--allowed-native-resolutions 512`、`pilot512.json` 与新路径；1024 同理。**单次 HENMO CLI manifest/config 必须对应一个真实 native side**，不得以混合 side 的 export 替代这项检查。失败时提交错误与拒绝回执，不伪造可加载清单。

### 交付资产与字段

| 内容 | 必须能够追溯的字段/资产 |
|---|---|
| 身份和隔离 | `snapshot_id`、`record_id`、role/split、`source_group`、`geometry_id`、原网格 SHA256、TaskSpec/初值、旧 222 条映射 |
| 材料 | `material_identity`、`native_material_resolution`、完整/部分材料布局、固定材料、坐标/单位/密度、构建版本与参数、文件 SHA256 |
| 查询与教师 | `query_content_sha256`、`operand_content_sha256`、operation/保留侧、有限面片与端盖、参数/运动、教师版本及输出 SHA256 |
| 监督与资格 | 原生 M/固定 M/完整可编辑 M、`derivative_valid`、`derivative_dimension`、资格及拒绝原因、事件邻域、原生终点验收 |
| 覆盖 | `surface_family`、原生保留比例/分档、`trajectory_stage`，实际加载与资格分母 |
| oracle 重建 | 同查询/材料/教师身份，Work B 提供的层级、原子构建配置、原子资产及 SHA256、固定扣除项记录 |

以上是资产间必须可追溯的信息；沿用已有 schema 的合法位置，不要求把所有内容硬塞进训练 manifest。新增诊断索引另存 sidecar，并用哈希关联。

exporter 实际生成 `training_manifest.json`、`export_receipt.json` 及引用资产；audit 输出位置由上面命令指定。**以下为本轮要求新增编制的交付文件，现有 CLI 不会自动全部生成：**

- [ ] `WORK_A_DELIVERY_RECEIPT_R2.md`：版本、已完成项、阻断项、可用实验范围、缺失证据。
- [ ] `material_moment_validation.json`：独立原网格/完整材料/固定壳逐分量误差及缩放定义。
- [ ] `oracle_input_index.jsonl`：冻结同查询输入和重建索引；原子侧资产待 Work B 回传后补齐绑定。
- [ ] `coverage_matrix.csv`：按上述维度整理审计结果，不把未知字段归入已覆盖。
- [ ] `sealed_evaluation_index.json`：封存独立来源和初值身份；对应验证资产单独交付，绝不混入训练 manifest。
- [ ] `SHA256SUMS`：覆盖 manifest、回执、配置、引用资产及上述附加文件；移动目录后再次验证可解析与哈希一致。

## 六、完成判定与向 Work B 回传

完成回执写清：哪些资产已通过真实模式读取、材料与标签验证，哪些查询可用于 M+J、哪些仅 M，oracle 输入是否可重建，R8/Full-J/终点/独立来源还缺什么。**“可开始短 Pilot”“表示能力诊断完成”“可以长训练”“可推广到独立来源”是四件不同的事。** Work A 交付首批合格资产即支持 Work B 开始限定范围的诊断和短训；长训及推广仍由实际查询精度、有效导数、原网格合格率和完整耗时决定。

本清单是执行要求，不代表上述新增报告已生成、真实材料已过验或模型已获长训资格。

`combB_R3_021` 的第一个原始切向列提供了一个可重放的例子。步长 2×10⁻⁵ 时，Moment 的中心差分与解析材料导数的相对误差仅 1.23×10⁻⁶。沿负方向、中心和正方向直接清点三角网格的顶点、边、面，欧拉特征数依次为 −202、−202、−200。该扰动超出此查询的已证明范围。另做的四次原生调用复核了同一现象，并在证书半径内取两点重算。两侧原始系数实际位移均为 1.16×10⁻¹⁰，此时欧拉特征数均为 −202，所有顶点构造及有向三角面对应相同。这个针对已发现变化所做的补充算例单独计数。[两档尺度的实际网格与十矩](evidence/event_scale_example.json)

## 原生求解器如何使用这 3 列或 8 列导数

对静平衡最大质量目标，原生 C++ 求解器在斜平面四面体上组装出 6×6 的 Newton 方程，在正式开发查询 `R02_R8_032` 上组装出 11×11 的方程。后者实际收到的十个系数与登记值逐位相同，保留网格的几何和拓扑摘要也相同。将求解器收到的八列导数换回原始查询坐标，与独立有向四面体积分的最大绝对差为 4.68×10⁻¹⁷。按原生混合项的系数 2 换回 Newton 坐标后，与 C++ 保存的方向矩阵最大相差 1.04×10⁻¹⁷。

把同一平面切换到 `FIDGET_SPINNER` 目标后，材料导数仍有数值。由于约束或目标梯度超出给定空间，求解器拒绝组装方程。三个算例都预设只调用一次。一般 R8 的切空间随迭代点变化，此处实测范围是起点的线性化。[原生返回的矩阵、导数和拒绝原因](solver_bridge/receipt.json) · [接口与独立复算](solver_bridge/README.md)

## 原生面条求解回归

Noodles v8 种子 0 通过历史原生入口和新服务的普通十参数入口分别执行了完整 Newton 求解。两者均为 25 次函数调用，第 3 次重现原锥面拒绝，最终网格均通过独立物理验收。相对冻结轨迹，24 次有效 Moment 的最大绝对差为 0，原始 J 的最大绝对差为 1.78×10⁻¹⁵，求解轨迹摘要一致。43 个事件逐字段复核后，实际差异来自计时以及同一次拒绝的 Python 调用位置。两个真实运行的原始事件摘要均可从完整数据逐字节重算。这里的计时取自并行审计期间的原生运行，仅供复核。替代原生求解器的成功率、配对耗时与加速比仍待满足训练准入后测量。[两次原生求解对照](evidence/noodles_event_comparison.json)

下一步优先补齐正式训练集剩余 7,149 条及开发集剩余 132 条的同口径物理回执。每条记录分别保留有效 Moment、可用导数及适用范围，或原生拒绝和原因。完成整套覆盖后，再按已冻结的三臂方案复核训练准入。两条超筛查线的 combB 抛物面可继续作为固定回归查询。

## 3. 本轮可以立即启动的命令

完整参数、路径准备和产物检查见 [Work B 执行清单](WORK_B_EXECUTION_R3_2026-11-28.md)。当前真实存在的入口是：

```text
python -m experiments.henmo_v1plus.cli audit-data ...
python -m experiments.henmo_v1plus.cli diagnose-paths ...
python -m experiments.henmo_v1plus.cli diagnose-gradients ...
python -m experiments.henmo_v1plus.cli compare ...

```

上面是入口索引，不是可直接粘贴执行的完整命令。不要把 `...` 当参数。Work B 文件提供完整模板。

当前没有 `stop`、`benchmark`、`promote`、`solve` 子命令，也没有根据 5% 指标自动早停或晋级的控制器。停止旧任务使用 Work 已有进程管理；原生求解使用现有已注册 solver callback。不得虚构一条验收命令，或将 CLI 退出 0 当作物理通过。

## 4. 每阶段的通过条件

| 阶段 | 允许下一步的条件 | 不能据此声称 |
|---|---|---|
| 软件与身份 | 预检通过；源权重、dtype、配置、快照、查询身份核对一致 | 真实几何精度合格 |
| 数值保持 | 同权重同输入的原始 M/J 在事先登记的浮点容差内一致；完整开发覆盖核对无缺失 | 已修复旧模型退化 |
| 归因 | 已确认数据/教师口径一致，失败被复现，并有一个可检验的修正假设 | 已定位所有几何的唯一根因 |
| 128 步短筛选 | 预算完整、记录齐全；能区分 M-only、joint 与无学习参考的作用 | 已满足长训或原生优化条件 |
| 扩大预算 | 在声明部署路径检查原 5% Moment 主线及各保护项；另有基线、分来源和终点证据 | 仅凭 coarse 诊断即可部署 |
| 最终部署/论文 | 独立来源、冻结初值、同质量原网格验收与全成本比较 | 单查询耗时等于合格解加速 |

原已登记门槛继续保留：来源宏平均原始 Moment 相对声明的 E0 至少下降 5%，各预登记保护误差至多为对应 E0 的 1.05 倍。若沿用原 E0 `2.5324920350532497e-7`，Moment 线是 `2.405867433300587e-7`；新阶段另有自己的 E0 时必须同时列出，不能用较差的 E5 人为降低比较难度。Full-J、低保留或终点缺有效分母时写“证据不足”，不能签发该项通过。

这些精度门槛不阻塞无更新诊断，也不要求失败旧权重先合格才能进行 128 步定位实验。通过线不随结果事后放宽。
